# Canonical Tags

Use these before inventing new ones. Keep the list small and meaningful.

## Type / structure
- `#project/<slug>` — belongs to a project
- `#area/<slug>` — belongs to an area
- `#person/<slug>` — about a person

## Status / workflow
- `#open` — live thread, needs attention
- `#followup` — explicit follow-up owed
- `#done` — closed / resolved

## Source
- `#call` — originated from a call transcript
- `#meeting` — originated from a meeting

## Rules
- Lowercase, kebab-case slugs (`#project/maestro-v2`).
- One status tag at a time per item.
- Prune `#open`/`#followup` during weekly review.
