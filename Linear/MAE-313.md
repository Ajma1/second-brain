# [ACPF-5] Idea bank schema plus search and selection capabilities

- **Identifier:** MAE-313
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-20
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-313/acpf-5-idea-bank-schema-plus-search-and-selection-capabilities

## Goal

Create the persistent client idea bank so generated ideas are durable, searchable, explainable, and selectable for drafting.

## Scope

* Add/adjust schema for idea bank items.
* Scope ideas per client persona while supporting agency-wide search/filter.
* Store hook/title, short angle, evidence references, persona/voice fit, suggested format, confidence score, source run, status, createdAt, updatedAt.
* Implement small capabilities such as `listPostIdeas`, `searchIdeaBank`, `shortlistPostIdea`, `selectPostIdea`, and `archivePostIdea`.
* Track idea lifecycle without conflating ideas with post drafts.

## Acceptance

* Agency can list and search all ideas across clients.
* Client view can show only that client's ideas.
* Selecting ideas is durable and usable by the first-week drafting workflow.
* Tests cover scoping and search/filter behavior.
