# [E1-7.2] Gate streaming — integrate gate-run tracking into generatePost workflow

- **Identifier:** MAE-340

PR-2 of MAE-245 [E1-7] Gate streaming. Stacks on PR #180 (`feat/gate-runs-tracking-MAE-328`).

Wires the existing `workflows/generatePost.ts` workflow with `startGateRunInternal` + `finishGateRunInternal` calls from PR-1. Each gated step writes a live, reactive `gateRuns` row per phase per piece, which the UI subscribes to in PR-3.

Phase mapping:

* `generateDraftStep` → `"generation"`
* `lintPieceStep` → `"lint"`
* `evaluateDraftStep` → `"grounding"`
* `attachVerdictStep` → `"review"` (or no gate-run, decided per workflow honesty)
* `createPieceStep` → no gate-run (internal data-structure write)

Try/finally semantics ensure `finishGateRunInternal` fires with `status:"failed"` + error code on step error, `status:"passed"` on success. Workflow stays a thin composition — every step.run* targets `internal.capabilities.<domain>.<verb>`.

OUT OF SCOPE: live UI subscription + streaming text (PR-3).
