## Product direction from spike

* User edits directly in a LinkedIn-style feed card, not a generic editor plus preview.
* Convex owns document sync through `@convex-dev/prosemirror-sync`.
* BlockNote is viable for the prototype, but production must decide early whether to keep BlockNote or drop to raw TipTap for control.
* Convex Agent + Claude can provide draft collaboration and selected-text edits.
* Selected-text AI editing needs a state machine: capture selection, queue job, parse structured replacement, apply only if target text matches uniquely, and allow rollback.
* Fast apply plus rollback felt better than explicit confirm/reject for every small edit.
* Evals, highlights, agent turns, snapshots, and edit events should live in sidecar records outside the post body.

## Scope

Turn the prototype into a product feature plan and implementation package.

1. Decide BlockNote vs raw TipTap before real customer documents are stored.
2. Integrate the editable feed-card writing surface into the product app shell.
3. Replace demo IDs with tenant/user/draft/content object IDs.
4. Wire Convex sidecar records into the content object/evidence schema.
5. Preserve selected-text queueing, unique-match replacement, parser hardening, and rollback controls.
6. Add production auth/permissions and version history.
7. Keep LinkedIn publishing out of this feature unless a separate publish/auth workflow approves it.
8. Carry over deterministic tests for parser behavior, selection matching, edit queue state, toolbar positioning, and LinkedIn evals.

## Acceptance criteria

* Product spec is updated with the editable feed-card workspace decision.
* Implementation identifies the editor choice and migration risk explicitly.
* A working product-integrated version supports human editing, Joni selected-text edits, rollback, sidecar evidence, and deterministic evals.
* Human edits and Joni-applied edits produce structured evidence suitable for edit learning.
* No LinkedIn mutation/publish action is exposed without auth and approval gates.
* Prototype learnings are linked from the related editor/edit-learning issues.
