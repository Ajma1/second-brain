# [ACPF-14] Capability/workflow contract tests and CLI/UI parity guard

- **Identifier:** MAE-322
- **Status:** Done
- **Assignee:** Tim Keen
- **Team:** MAE
- **Updated:** 2026-06-28
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-322/acpf-14-capabilityworkflow-contract-tests-and-cliui-parity-guard

## Goal

Protect the clean architecture by testing capability contracts, workflow sequencing, and UI/CLI parity for the foundation epic.

## Scope

* Add focused tests for capability inputs/outputs and agency/client scoping.
* Test onboarding sequence: client create -> Harvest intake -> summaries -> idea generation.
* Test first-week drafting sequence: select 7 ideas -> draft 7 posts -> review/approval state.
* Add a parity guard or documented checklist that ensures every UI action has a CLI command and both call the same backend surface.
* Include regression tests for admin read boundaries where feasible.

## Acceptance

* Foundation workflows have tests before or alongside implementation.
* UI and CLI cannot drift into separate business logic paths unnoticed.
* Tests cover happy path plus at least one failure/retry path for Harvest onboarding.
