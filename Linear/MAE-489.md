## Problems (3 related issues in the post editor)

### 1\. CMO agent crashes

Clicking "Ask CMO" opens the agent panel. Typing "how can I change persona in posts" triggers "AUTOPILOT · RUN STARTED" then immediately shows "Workspace agent snag — try again."

### 2\. Cannot switch persona

The post editor shows "malaika" persona badge in the header. There is no UI to switch to a different persona (e.g. Tim Keen). The badge is not clickable for selection.

### 3\. Slash commands don't work

Typing "/" in the post editor body does nothing — no command palette appears despite the placeholder text saying "Enter text or type '/' for commands."

## Steps to reproduce

1. Go to /posts
2. Open an existing post (or the page after reload from [#3614](https://linear.app/modern-agency-sales/issue/MAE-488/bug-posts-page-crashes-on-first-load-works-after-reload))
3. Try clicking the persona badge — not switchable
4. Try typing "/" in the editor — no commands
5. Click "Ask CMO" → type anything → "Workspace agent snag"

## Expected behavior

* Persona should be selectable per post
* Slash commands should open a command palette
* CMO agent should respond with guidance
