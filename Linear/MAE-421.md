## Goal

Make the local HTML/template gallery useful for scanning graph v2 recommendations, evidence, hooks, lead magnets, and review readiness.

## Files

Modify:

* `tooling/corpus/render-linkedin-template-gallery.mts`

## Work

Add gallery support for graph v2 artifacts and filters/sections for:

* graph edge type
* cluster/topic
* lead magnet flag
* hook type and secondary hook types
* recommendation evidence
* confidence bands
* readiness/review status
* low-confidence candidates

The gallery should show enough context to scan posts/templates and recommendations, while hiding raw third-party actor display data by default.

## Constraints

* Do not expose raw third-party actor names, headlines, companies, or display URLs in default gallery output.
* Keep the gallery local/static; no customer-facing UI in this task.
* Preserve existing gallery behavior for template candidate scanning.

## Verification

Run the focused gallery/tooling test command used in this repo, plus a smoke render against the current artifact directory if available. Use `rtk` and `host-test-slot` for tests.

## Acceptance Criteria

* Gallery can render graph v2 recommendation/evidence fields from local artifacts.
* Filters make lead magnets and hook classes easy to inspect.
* Default rendered output respects the privacy redaction rule.
