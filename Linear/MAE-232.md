Stories:

1. As a ghostwriter, every generated draft passes named deterministic lint gates before it can ship — banned phrases, punctuation/markdown artifacts, missing source links, capitalization style, hook shape, channel constraints — with actionable failure messages that route generation back to fix. [GC-004]
2. As an agency owner, lintable issues are caught at ~100%, not 90% — every promoted rule ships with positive+negative fixtures and a regression test, and a 90%-reliable check is treated as a defect. Unlintable taste issues are explicitly labeled and routed to review, never claimed deterministic. [GC-014]
3. As a content operator, my repeated edits become concrete rule candidates typed as banned_phrase / required_source_link / capitalization_style / hook_shape / punctuation — each with source-edit ids, before/after examples, confidence — promoted only with fixtures + my approval. [GC-015]
4. As a content operator, every edit is captured (before/after/diff/editor/tenant) and classified taste / defect / operational — taste edits propose voice changes with evidence; I can inspect which edits produced a rule. [GC-003]
5. As an agency owner, defect-class edits become failing eval cases so the same mistake can't ship twice.
6. As a ghostwriter, I can run the improvement lab on a module and review before/after evidence before keeping the change.
