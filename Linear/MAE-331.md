# [E1-3.2] Client review link HTTP route — anonymous token-gated read

- **Identifier:** MAE-331
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-331/e1-32-client-review-link-http-route-anonymous-token-gated-read

PR-2 of MAE-241 [E1-3]. Stacks on PR #172 (`feat/client-review-token-MAE-325`).

Adds the public HTTP route `GET /review/:token` that verifies the signed review token via `internal.capabilities.reviewTokens.resolveReviewTokenInternal` and returns a read-only JSON payload of the piece's current content for the anonymous client-review surface. The internal query `getReviewPiece({ workspaceId, pieceId })` is gated by the HTTP layer's token verdict — `workspaceId` and `pieceId` come ONLY from the verified token, never from caller args (NO_CALLER_SUPPLIED_IDENTITY). Failure modes map to typed error codes (`REVIEW_TOKEN_*`) per Charter §7.

The comments table, approve mutation, and the anonymous client UI page land in PR-3 + PR-4 of MAE-241.
