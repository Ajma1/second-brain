# Workflow catalog fails to load: 'Workflows could not be loaded'

## Bug

The Workflows page at `/workflows` shows "Workflows could not be loaded." for the Workspace view. The entire workflow catalog is inaccessible.

**Significance:** Workflows are Maestro's core orchestration primitive — every multi-step content operation (repurposing, planning, generation, optimization) runs through this system. A broken catalog means users cannot browse, run, or manage any workflow.

**Expected:** Workflow catalog loads with available workspace and system workflows.

**Actual:** Error message "Workflows could not be loaded." with empty catalog.

**Query path:**

1. `useWorkflowRailTemplates("workspace")` → `useSafeQueryResult(listWorkflowCatalogRef)`
2. Backend: `capabilities/workflow/catalogs:list`
3. Reads `GENERATED_MAESTRO_WORKFLOW_MANIFEST_SET` + `workflowCatalogFamilies` + reconciliation receipt

**Possible causes:**

* `GENERATED_MAESTRO_WORKFLOW_MANIFEST_SET` not built or corrupt (build-time artifact)
* `workflowManifestReconciliationReceipt` missing or stale
* Staging deployment didn't run workflow manifest generation
* Database query timeout on workflow tables

**Error source:** `apps/web/src/features/workflows/workflow-rail-templates-adapter.ts:63`

**Files:**

* `apps/web/src/features/workflows/workflow-rail-templates-adapter.ts` (error display)
* `packages/convex/convex/capabilities/workflow/catalogs.ts` (catalog query)
* `packages/convex/convex/registry/generatedMaestroWorkflowManifestSet.ts` (build-time manifest)
