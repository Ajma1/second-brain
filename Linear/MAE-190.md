## 2026-05-21 Update

Convex is now the accepted v0 product-runtime direction. Temporal/Hatchet remain parked fallback comparators if Convex hardening fails.

## Current Decision

* Convex owns operational product state, Workflow/Workpool orchestration, realtime status, bounded streams, and context indexes.
* Vercel AI SDK owns provider-neutral model calls and streaming.
* `@maestro/content-gates` owns deterministic readiness.
* The grounded client brain is markdown/frontmatter/wiki-link first, indexed by Convex; RAG is optional semantic recall only.
