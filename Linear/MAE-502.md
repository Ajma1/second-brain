# CMO agent shows generic 'Workspace agent snag' instead of actual error reason

- **Identifier:** MAE-502
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE

## Bug

When the CMO agent fails due to insufficient credits, the user sees a generic message:

> Workspace agent snag — try again.

The actual error is `CREDIT_INSUFFICIENT` — "Add credits before generating." (visible only in the browser console).

**Expected:** The error message should surface the real reason — e.g., "Insufficient credits — add credits before generating." — so users know what action to take.

**Actual:** Generic "snag" message with no actionable guidance. Users have to open DevTools to find the real error.

**Console error:**

```
[CONVEX A(agents/cmoMessages:sendMessage)] Server Error
Uncaught ConvexError: {"code":"CREDIT_INSUFFICIENT","message":"Add credits before generating."}
  at typedError (./../convex/adapters/errors.ts:295:0)
  at assertCreditGateAllowed (./../convex/adapters/creditGateLifecycle.ts:301)
  at async preflightAndChargeCreditGate (./../convex/adapters/creditGateLifecycle.ts:99:2)
```
