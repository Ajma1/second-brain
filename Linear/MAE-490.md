# feat: import Claude/ChatGPT conversation history as source context

- **Identifier:** MAE-490
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-08-01
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-490/feat-import-claudechatgpt-conversation-history-as-source-context

## User need

Aman (front-end dev, Medium blogger, wants LinkedIn visibility) has extensive Claude chat history with context about his writing, topics, and voice. He can't import it into Maestro — has to manually convert to PDF/doc first.

**Aman's words:** "Requires heavy context-setting upfront" with Claude every time he starts a new session.

## What this solves

Ghostwriters and content creators build up significant context in Claude/ChatGPT conversations — voice preferences, topic history, feedback loops. Losing this context when switching to Maestro is a migration barrier.

## Proposed solution

Accept Claude/ChatGPT export formats (JSON, PDF, or doc) as a source context import into Brain. Extract voice patterns, topic preferences, and writing style from conversation history.

Related existing surface: `brain.sourceContextImports.create` — could be extended to parse conversation export formats.

## ICP evidence

* Aman: can't import Claude history directly, needs document format
* Ali (call): loads "personas of admired writers" into AI — similar context-loading need
* General pattern: ghostwriters have context scattered across Claude, ChatGPT, Notion, Google Docs
