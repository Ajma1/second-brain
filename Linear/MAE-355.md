# LinkedIn analytics ingestion — pull available post metrics into platform

## User Story

**As a LinkedIn ghostwriter, I want to see LinkedIn performance metrics (impressions, likes, comments, reposts) for each post within Maestro, so that I don't have to manually check LinkedIn analytics separately.**

## Source

Dalton Danks call (2026-06-18). Dalton currently checks LinkedIn analytics manually and cares most about engagement signals that indicate resonance.

> "what I actually care about… I would say saves and like message shares are actually more indicators for me in terms of like how something resonated"

**Note:** LinkedIn API does NOT provide profile views, saves, or DM shares. Available metrics are limited to impressions, likes, comments, and reposts.

## Prior Art (reference for concepts, not code to port)

**maestro-v2-3** (~65% built):

* Full LinkedIn OAuth with HMAC state signing, AES-256-GCM token encryption, daily token refresh cron
* `postAnalyticsPulls` table: scheduled pulls 24h after publish
* `agents/attribution.ts` — getAnalytics/getAttribution queries
* `analytics-client.tsx` — dashboard with summary metrics, content performance table, attribution sources
* **Missing:** No live LinkedIn/ConnectSafely API call for actual metrics, no cron for processing pulls
* OAuth scopes: `openid, profile, email, w_member_social` — missing analytics scopes

**mas-platform** (fully built):

* `trigger/scrape-post-performance.ts` — daily Apify scrape at 6am UTC
* `post-metrics-refresh.service.ts` — manual refresh with per-minute idempotency
* `cp_post_performance` table: views, likes, comments, shares, impressions, engagement_rate, captured_at
* `content-pipeline/metrics-staleness.ts` — freshness classifier (FRESH=30min, VERY_STALE=180min)
* `InlineMetrics.tsx` — impressions/likes/comments/shares/ER with sparkline
* AI performance analyzer with Claude Sonnet for pattern insights
* Engagement feedback loop: boosts topics of top-quartile posts

## Implementation Notes

mas-platform's Apify scraping approach works but adds a dependency. Consider LinkedIn Community Management API (r_organization_social scope) for org pages, or the basic share statistics endpoint for personal profiles. The staleness classifier and inline metrics UX from mas-platform are solid patterns. The AI performance analyzer is a nice differentiator.
