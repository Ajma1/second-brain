## Why

Content must never become ready/exportable/synced/published until deterministic gates pass. Repairable failures should self-heal automatically.

## Scope

* Create prototype `@maestro/content-gates` with 8-12 rules.
* Seed fixtures for missing source links, AI tells, bad LinkedIn formatting, unsupported claims, duplicate hooks, voice violations, markdown artifacts, and CTA/source mismatch.
* Run gates from a Temporal Activity.
* Add bounded repair loop with two attempts, then `needs_human_review`.

## Success Metrics

* First lint-passed ready post: P50 < 60s, P90 < 120s.
* Repair success rate: >=80% first repair, >=90% within two repairs for seeded repairable defects.
* 100% of seeded blocking defects are blocked.
* 100% of final failures include object id, version id, rule id, location, severity, and fix guidance.
* 0 exports/syncs/publishes from non-ready versions.
