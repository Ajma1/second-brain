# [E1-9.2] Agent door — HTTP route /agent-door/:token (read + propose)

- **Identifier:** MAE-345
- **Status:** In Review
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17

Stacks on PR #188 (feat/agent-door-session-MAE-333).

PR-2 of MAE-247 [E1-9] CLI door — the HTTP surface.

## Goal

Token-gated streaming HTTP endpoint that lets an external CLI agent read the piece + post annotations. Mirrors the MAE-241 PR-2 HTTP route pattern (#184).

## Files

* `packages/convex/convex/http.ts` — extend. Register `/agent-door/:token/piece` (read) + `/agent-door/:token/propose` (write).
* `packages/convex/convex/adapters/agentDoorRoutes.ts` — NEW. Three layered gates per route: `isOriginAllowed` + shared route bucket + per-token bucket. Mirrors the MAE-241 PR-2 `adapters/reviewLinkRoutes.ts`.
* `packages/convex/convex/capabilities/agentDoorView.ts` — NEW. Internal queries the routes call.
* `packages/convex/convex/adapters/env.ts` — extend with `getAgentDoorRouteEnv()` reading `AGENT_DOOR_ALLOWED_ORIGINS`.
* `packages/convex/convex/adapters/rateLimit.ts` — extend with `agentDoorRoute` + `agentDoorPerToken` buckets.
* `tooling/quality/check-http-gate.mts` — extend to assert the new routes call the three gates in order.
* `tooling/eslint-plugin-maestro/rules/confine-http-router.mjs` — extend allowlist with `./adapters/agentDoorRoutes`.

## Out of scope

* Streaming transport (PR-3)
* CLI binary (PR-4)

## Constraints

* Three gates in order: origin allowlist → shared route bucket → per-token bucket. Awaited. Guarded by `if (!verdict.ok) return …` BEFORE any `ctx.runQuery`. The `check-http-gate.mts` AST gate enforces this.
* ConvexError-from-enum.
* No `v.any()`.
* Origin allowlist + rate limits per Charter §8.6.
