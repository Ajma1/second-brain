# feat: image upload and paste support in CMO chat

## Feature

Allow users to upload or paste images directly into the CMO chat input. This would let ghostwriters share screenshots, reference visuals, and provide visual context to the agent without leaving the conversation.

**Use cases:**

* Paste a screenshot of a LinkedIn post for the CMO to analyze or rewrite
* Upload a client's brand asset for reference when generating content
* Share a competitor's post layout for inspiration
* Paste error screenshots when asking for help

**Current behavior:** CMO chat input is text-only — no image upload, drag-and-drop, or clipboard paste support.

**Expected behavior:** Users can paste (Cmd+V) or drag-and-drop images into the CMO input. Images are sent as part of the message context to the agent model (which supports vision).
