# [ACPF-1] Client persona schema and capability spine

- **Identifier:** MAE-309
- **Status:** In Review
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-19
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-309/acpf-1-client-persona-schema-and-capability-spine

## Goal

Define the agency-owned client persona foundation without confusing client personas with authenticated users.

## Scope

* Add/adjust schema for agency-owned client personas.
* Required fields: client name, LinkedIn profile URL.
* Optional fields: website, offer, audience/ICP, content goals, cadence, notes/files.
* Track onboarding status, Harvest status, persona/voice summary status, and idea generation status.
* Add small capabilities such as `createClientPersona`, `listClientPersonas`, `getClientPersona`, and update/edit capabilities as needed.
* Ensure all capability contracts are usable by UI, CLI, admin, and future agents.

## Notes

* A client persona is not an auth user.
* v1 assumes a single authenticated agency operator.
* Keep schema declaration-only and aligned with `AGENTS.md` / `docs/architecture.md`.

## Acceptance

* Client persona records are agency-scoped.
* UI/CLI/admin can all address the same persona by stable ID.
* Tests cover agency scoping and required LinkedIn URL validation.
