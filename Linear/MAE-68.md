# 6.6 · The trace (provenance) view

- **Identifier:** MAE-68
- **Status:** Backlog
- **Assignee:** ajmal@maestrogtm.com
- **Team:** MAE
- **Updated:** 2026-05-21
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-68/66-the-trace-provenance-view

**Why.** This is the moat made *visible*. The trace view is a first-class screen over `trace.node`: point at any generated asset and see it broken down into objects → brain claims → the real Reddit thread / transcript line behind each one. It's what an operator shows a client to prove every line of a campaign traces to a real source.

**What.** A trace screen — given an object or campaign, render the provenance graph down to artifacts (with source URLs/quotes); given a claim, render the campaigns that use it.

**Read first.** [Team Onboarding — "Why it matters: provenance"](<https://github.com/modernagencysales/maestro-agent-planning/blob/main/docs/operator/specs/active/gtm-client-lead-loop/team-onboarding.md>) · [Spec 6 — Cockpit](<https://github.com/modernagencysales/maestro-agent-planning/blob/main/docs/operator/specs/active/gtm-client-lead-loop/specs/cockpit.md>)

**Done when.** The trace screen, given a generated object or campaign, renders the full provenance graph down to artifacts with their source URLs/quotes, and given a claim renders the campaigns that use it.
