# [E1-6.3] Stalled-review — periodic scan workflow + alerts table

- **Identifier:** MAE-343
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-343/e1-63-stalled-review-periodic-scan-workflow-alerts-table

PR-3 of MAE-244 [E1-6] Stalled-review exception. Stacks on PR #178 (`feat/review-exceptions-capability-MAE-326`).

## Goal

A periodic Convex cron that calls `listReviewExceptionsInternal` per workspace + raises alert rows the UI can subscribe to. ~250 LOC.

## Files

* `packages/convex/convex/crons.ts` — NEW. Hourly cron registers a kickoff into the durable workflow.
* `packages/convex/convex/workflows/reviewExceptionScan.ts` — NEW. Workflow that:
  1. Fans out per workspace (page through `workspaces` table).
  2. Resolves per-workspace `thresholdMs` from policy at workflow start.
  3. Calls `listReviewExceptionsInternal({ thresholdMs, now, pageSize, cursor })` paginating until isDone.
  4. For each exception found: inserts a row into `reviewExceptionAlerts`.
* `packages/convex/convex/schema/reviewExceptionAlerts.ts` — NEW table:
  * `{ workspaceId, pieceId, reasons, detectedAt, acknowledgedAt?, acknowledgedByUserId? }`
  * Indices: `by_workspace_acknowledged`, `by_piece_detected`.
* `packages/convex/convex/capabilities/reviewExceptionAlerts.ts` — `listForWorkspace`, `acknowledge`.
* `packages/convex/convex/policy/kinds/reviewExceptionScanInterval.ts` + `reviewExceptionThreshold.ts` — NEW seeds.

## OUT OF SCOPE

* UI surface (separate slice).
* Email/Slack notifications.

## Constraints

* Cron cadence is a `// invariant:` engineering value.
* Per-workspace threshold is policy.
* Inject `now` at workflow start; don't read clock mid-flow.
* ConvexError-from-enum (add `ALERT_NOT_FOUND`, `ALERT_ALREADY_ACKNOWLEDGED`).
* No `v.any()`.
