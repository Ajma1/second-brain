# [ACPF-12] Repo-local CLI foundation with WorkOS auth and parity commands

- **Identifier:** MAE-320
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-320/acpf-12-repo-local-cli-foundation-with-workos-auth-and-parity-commands

## Goal

Make the CLI a first-class Maestro surface that can execute the same v1 actions as the UI.

## Scope

* Create/extend a repo-local CLI package or app following the clean repo architecture.
* Use WorkOS auth and store a local session/token for subsequent commands.
* Add commands for client onboarding, onboarding status, idea bank list/search, idea selection, drafting selected ideas, draft list/edit/revise, approve, schedule, and admin monitor reads.
* Route commands through backend capabilities/workflows rather than duplicating business logic.
* Design command names and output formats for later distributable CLI packaging.

## Acceptance

* Every v1 UI action has a CLI equivalent.
* CLI can authenticate with WorkOS.
* CLI output is readable for humans and stable enough for scripts where practical.
* No Harvest calls or model prompts live directly in CLI command handlers.
