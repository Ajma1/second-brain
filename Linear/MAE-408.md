## Goal

Add a pure parser for Harvest comment/reaction pages so provider response variation is normalized at the boundary.

## Files

Create:

* `packages/convex/convex/adapters/harvestEngagementParser.ts`
* `packages/convex/convex/adapters/harvestEngagementParser.test.ts`

## Work

Implement parser functions:

* `parsePostCommentsPage`
* `parsePostReactionsPage`
* `parseProfileCommentsPage`
* `parseProfileReactionsPage`

Normalize each engagement event into:

* provider event ID
* event type: comment or reaction
* comment text or reaction type
* occurred timestamp in seconds when available
* actor object with ID, name, LinkedIn URL, headline, title, company
* target post URL and target author name for profile-level outbound engagement
* pagination cursor

## Constraints

* Parser is pure and should not call Harvest.
* Actor identity can vary; support common alternate field names.
* Post-level engagement rows without actor identity should throw.
* Preserve raw actor fields only inside the parser output; later default artifacts must redact them.

## Acceptance Criteria

* Parser tests cover comments, reactions, outbound profile activity, pagination, and missing-identity failure.
* Normalized types are exported for the Harvest adapter gateway.
* No network calls are introduced in parser tests.
