## Goal

Convert cached embeddings into useful creator-level semantic edges without doing expensive all-pairs comparison.

## Files

Create:

* `tooling/corpus/beneficial-adjacency/vectors.mts`
* `tooling/corpus/beneficial-adjacency/embedding-graph.mts`

Modify:

* `tooling/corpus/linkedin-beneficial-adjacency.test.mts`

## Work

Implement:

* Vector helpers for cosine similarity, centroid, normalization, finite-value validation, and top-K selection.
* Creator embedding input extraction from profile text, recent posts, and outlier/template posts.
* Semantic edge generation using cached embeddings and bounded top-K neighbor search.
* Edge output with creator IDs, edge type, score components, evidence input IDs, model ID, cache keys, and confidence.

## Constraints

* Do not require all-pairs creator comparison for large corpora; keep top-K/batching viable.
* Missing embeddings should lower confidence or skip edges gracefully, not crash the whole run.
* Artifact outputs with evidence should prefer JSONL.

## Verification

Run:

```bash
rtk env HOST_TEST_MAX_LOAD_1M=100 host-test-slot --class focused pnpm exec tsx --test tooling/corpus/linkedin-beneficial-adjacency.test.mts
```

Expected: PASS.

## Acceptance Criteria

* Tests cover cosine similarity, centroid behavior, top-K ordering, finite-vector validation, and semantic edge generation.
* Generated edges are typed and include evidence/model lineage fields.
