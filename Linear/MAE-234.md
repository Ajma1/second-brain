**Owner:** Ajmal backend + Tim judgment · NEW — GC journey 3; seed: the Scout spike

Stories:

1. As a content performance operator, I maintain an approved watchlist of niche LinkedIn sources + keywords per client, and the system scans for relative outliers — posts beating that account's own baseline (10 likes usually, 40 today), not absolute-number winners. [GC-005]
2. As a content performance operator, outliers yield winning-topic and winning-format candidates separately — format captures structure without copying wording — and next week's batch can adapt them to the client's own context with citations back to the market claim. [GC-006]
3. As an agency owner, scans, generated posts, edits, and performance outcomes compound in one database — I can query which topic/format influenced a post and whether the adaptation later performed; stale/contradicted claims trace to affected content. [GC-007]
4. As a content performance operator, the system records whether adapted formats/topics performed, closing the loop into the brain as internal claims with confidence + citations.
