Human-directed migration from Next.js app router to TanStack Start with official Convex TanStack Query/Start integration, official WorkOS AuthKit TanStack Start integration, Intlayer i18n wiring, Cloudflare Workers runtime, Buildkite-only production deployment, and strict TanStack-specific frontend architecture gates.

Source plans:

* docs/superpowers/plans/2026-06-21-nextjs-to-vite-tanstack-router.md
* maestro/docs/superpowers/plans/2026-06-21-tanstack-cloudflare-deploy-i18n.md

Acceptance:

* Web runtime no longer uses Next app router.
* All old Next page routes map to TanStack Start routes.
* Convex uses official @convex-dev/react-query + TanStack Start wiring.
* WorkOS uses official @workos/authkit-tanstack-react-start wiring.
* Production deploy is Buildkite-only to Cloudflare Workers with Worker secrets supplied during deploy.
* Generated Intlayer artifacts are ignored.
* Custom architecture gates enforce TanStack Start layer ownership.
