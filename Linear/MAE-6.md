# 0j · Fold Phase 0 learnings into the specs

- **Identifier:** MAE-6
- **Status:** Backlog
- **Assignee:** ajmal@maestrogtm.com
- **Team:** MAE
- **Updated:** 2026-05-21
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-6/0j-fold-phase-0-learnings-into-the-specs

**Why.** Prototyping is only worth doing if it changes the plan. Phase 0 ends by closing the loop: every surprise becomes a recorded decision and a spec edit, so the structured build (Stage P onward) starts from corrected specs.

**What.** Turn each Phase 0 learning — thesys, the scrapers, the factory, the grounded-node primitive, C1, Tiptap, Honcho, visual generation, Spec Kitty — into Decision Log entries and concrete edits to the affected specs.

**Read first.** [Team Onboarding](<https://github.com/modernagencysales/maestro-agent-planning/blob/main/docs/operator/specs/active/gtm-client-lead-loop/team-onboarding.md>) · [Design doc — Decision Log](<https://github.com/modernagencysales/maestro-agent-planning/blob/main/docs/operator/specs/active/gtm-client-lead-loop/design-doc.md>)

**Done when.** Every Phase 0 spike (0a–0i) has a corresponding Decision Log entry in the design doc, each affected spec has been concretely edited to reflect what its spike taught, and a reviewer can trace every Phase 0 learning to a specific spec change before Stage P / Stage 0 begin.
