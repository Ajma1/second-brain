## Why

Golden Call 001 artifacts and active specs still contain historical `*.fabro` product-runtime language. The architecture decision now separates Fabro factory gates from Temporal product runtime.

## Scope

* Replace user-facing content runtime references with Temporal workflow contracts.
* Keep Fabro references only where they mean internal software factory/build/release gates.
* Mark generated customer-discovery artifacts as historical where they preserve the original route.
* Update Linear import/source manifests or create superseding delta manifests.

## Acceptance Criteria

* Active specs, staged project plan, charter, and coding standards agree with the ADR.
* Remaining `*.fabro` references are either factory-only or explicitly historical/superseded.
* Work-package docs point implementers to `runtime-architecture-update.md`.
* No Stage 4 implementation ticket implies Fabro owns product readiness state.
