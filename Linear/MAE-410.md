## Goal

Create reusable local artifact utilities for deterministic, resumable analytics runs.

## Files

Create:

* `tooling/corpus/beneficial-adjacency/lineage.mts`
* `tooling/corpus/beneficial-adjacency/jsonl.mts`
* `tooling/corpus/beneficial-adjacency/text.mts`

Modify:

* `tooling/corpus/linkedin-beneficial-adjacency.test.mts`

## Work

Implement and test:

* Stable text normalization and content hashing.
* Actor key helper that delegates to/aligns with the privacy contract.
* JSONL read/write helpers with directory creation.
* Lineage manifest builder that records run ID, source export manifest, corpus bounds, analytics version, model IDs, policy versions, counts, costs, cache hash, schema version, and timestamps where applicable.

## Constraints

* Outputs must be deterministic functions of input corpus, run config, schema/model versions, cache state/hash, and seed.
* Prefer JSONL for complex graph/evidence artifacts.
* Commands must use `rtk`; tests must run through `host-test-slot`.

## Verification

Run:

```bash
rtk env HOST_TEST_MAX_LOAD_1M=100 host-test-slot --class focused pnpm exec tsx --test tooling/corpus/linkedin-beneficial-adjacency.test.mts
```

Expected: PASS.

## Acceptance Criteria

* Utility tests cover stable hashing, actor key priority, JSONL round-trip, and lineage fields.
* Utilities are dependency-light and reusable by later CLI/report tasks.
