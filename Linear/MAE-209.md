# [FACTORY] Enforce Railway Fabro + Convex Agent Mode preflight

- **Identifier:** MAE-209
- **Status:** Done
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-05-21
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-209/factory-enforce-railway-fabro-convex-agent-mode-preflight

[MAE-208](https://linear.app/modern-agency-sales/issue/MAE-208/arch-019-build-side-by-side-hatchet-and-temporal-content-runtime) surfaced a factory operating error: the run was launched against local Fabro (`http://127.0.0.1:32276`, `sandbox.provider=local`) even though shared Maestro factory runs must use Railway-hosted Fabro.

Observed runs:

* `01KS49PEPC36RTYV0JE6S5M5TQ`: local Fabro run failed at `expand_goal` because Anthropic CLI was not configured on the local host.
* `01KS49SH2N3CDSFBA07YVMS2KM`: local Fabro run using a temporary Codex workflow failed because the local Codex CLI auth was API-key mode and lacked `api.responses.write`.

These local auth failures are not the correct blocker for Railway Fabro. Railway gateway status says `FABRO_SERVER` should point at `https://fabro-maestro-production.up.railway.app/api/v1` and Codex OAuth is connected inside the Railway gateway profile.

Acceptance criteria:

* Shared factory launch scripts fail before run creation if `FABRO_SERVER` points at localhost or `127.0.0.1`, unless an explicit `--allow-local` flag is set.
* [MAE-208](https://linear.app/modern-agency-sales/issue/MAE-208/arch-019-build-side-by-side-hatchet-and-temporal-content-runtime) and similar shared runs use `--server https://fabro-maestro-production.up.railway.app/api/v1` and an appropriate Railway/Daytona sandbox path.
* Railway preflight validates Fabro CLI auth to the Railway API before launch.
* Railway/Daytona preflight validates required subscription-auth material for agent backends (`CODEX_AUTH_JSON_BASE64`, `CLAUDE_CODE_CREDENTIALS_JSON_BASE64` or equivalent) in the remote environment, not the local laptop.
* Preflight output distinguishes control-plane auth (`FABRO_DEV_TOKEN`/Fabro CLI auth) from agent subscription auth (Codex/Claude auth material) and provider API keys.
* Documentation explicitly says local Codex/Claude auth only matters for intentionally local runs.

This blocks fully automated Fabro execution of [MAE-208](https://linear.app/modern-agency-sales/issue/MAE-208/arch-019-build-side-by-side-hatchet-and-temporal-content-runtime) until the launch path is corrected to Railway and the remote preflight is green.
