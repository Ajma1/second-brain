# [ACPF-13] Superadmin monitoring surface

- **Identifier:** MAE-321
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-321/acpf-13-superadmin-monitoring-surface

## Goal

Create the v1 admin panel/surface for superadmin read and monitoring across agencies and clients.

## Scope

* Admin can view all agencies and client personas.
* Admin can inspect onboarding runs, Harvest usage/errors, idea generation runs, drafting runs, approval activity, schedules, and recent activity.
* Add admin read capabilities such as `listAgencies`, `listClientPersonas`, `listOnboardingRuns`, `listHarvestUsage`, `listHarvestErrors`, `listIdeaGenerationRuns`, `listDraftingRuns`, and `listApprovalActivity`.
* Keep v1 admin read/monitor only unless a repair/retry action is explicitly required by onboarding.
* Respect WorkOS/admin authorization boundaries.

## Acceptance

* Superadmin can diagnose stuck onboarding or generation runs.
* Admin can monitor agency/client activity without impersonating regular agency flows.
* Admin data comes from backend capabilities, not direct table scraping in React.
