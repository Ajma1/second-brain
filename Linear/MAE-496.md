# feat: import from Notion, Google Docs, and Airtable

- **Identifier:** MAE-496
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-07-31
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-496/feat-import-from-notion-google-docs-and-airtable

## User need

Ghostwriters have existing client context, SOPs, and content templates in other tools. Switching to Maestro means losing that context or manually copy-pasting everything.

**In their words:**

* "paying for multiple tools (Notion, Claude, Granola, Airtable, etc.)"
* "Previously paid for Jasper and Taplio; neither got fully adopted"
* Uses Magic Post + Google Docs + Claude for reporting

## What Maestro has today

`brain.sourceContextImports.create` accepts raw text chunks. No connectors for Notion, Google Docs, or Airtable.

## Proposed solution

Import connectors for:

* **Notion** — pull pages, databases, and content templates
* **Google Docs** — pull documents and shared folders
* **Airtable** — pull bases with client data and content calendars

Each import maps to Brain source context so it's immediately available for generation.

* Heri: pays for Notion, Claude, Granola, Airtable
* Adam: previously paid for Jasper and Taplio, neither got adopted
* Nicole: uses Magic Post + Google Docs + Claude
