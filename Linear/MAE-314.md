# [ACPF-6] Generate 20-30 sourced post ideas after onboarding

- **Identifier:** MAE-314
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-314/acpf-6-generate-20-30-sourced-post-ideas-after-onboarding

## Goal

Generate the initial idea bank only after Harvest intake and voice/persona summaries complete.

## Scope

* Implement `generatePostIdeas` and `scorePostIdea` capabilities.
* Generate 20-30 ideas for a client persona.
* Use the three artifact classes: trending posts/ideas, working or performing posts/ideas, and voice/client persona.
* Include hook/title, short angle, Harvest-backed source evidence, persona/voice fit, suggested format, and confidence score.
* Resolve agency methodology policy areas where relevant.
* Persist the generation run, prompt/model metadata, and output ideas.

## Acceptance

* Onboarding workflow automatically creates 20-30 ideas after intake completes.
* Every idea has evidence/provenance and a confidence score.
* Re-running generation creates a traceable new run and does not silently overwrite previous ideas.
