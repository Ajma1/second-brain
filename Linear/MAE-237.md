# [EH-3] MAESTRO_DEMO_MODE no longer disables auth globally

- **Identifier:** MAE-237
- **Status:** Done
- **Assignee:** Tim Keen
- **Team:** MAE
- **Updated:** 2026-06-22
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-237/eh-3-maestro-demo-mode-no-longer-disables-auth-globally

`MAESTRO_DEMO_MODE` env flag must no longer bypass or disable authentication globally. Demo mode may restrict UI features but must never weaken auth enforcement.

Part of the EH hotfix series on maestro-v2-3.

---

## Prior art (verified 2026-06-12)

* **maestro-v2-3** `origin/main`: `packages/convex/convex/lib/auth/requireUserAccess.ts:≈84` — `assertSelfUserUnlessDemo` has `if (isDemoModeEnabled()) return;` at the top (`:≈88`); `isDemoModeEnabled()` reads `process.env.MAESTRO_DEMO_MODE` (`:≈97`). This is the global off-switch to eliminate.
* **maestro-v2-3** `origin/main`: same file — `assertSelfUser` + `requireUser` are the fail-closed primitives that should apply unconditionally after this fix. Verdict: **REBUILD-AS-SPEC** — remove the demo-mode branch entirely; demo restrictions belong in UI layer only.
