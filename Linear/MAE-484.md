# bug: posts.generate returns 500 on staging

- **Identifier:** MAE-484
- **Status:** Done

- **Team:** MAE

## Problem

`maestro headless call posts.generate` returns HTTP 500 Internal Server Error on staging regardless of arguments.

Tested with:

* Simple topic only: `{"topic":"Voice bleed across clients"}`
* With persona ID: `{"topic":"...","clientPersonaId":"xn7ck6xk3b5vheb9q6s6ezc4an8bcfyp"}`
* With full context (angleHint, audienceHint)

All return the same 500 with no additional error detail.

## Possible causes

* Persona in `draft` status (persona activation isn't exposed as a headless surface)
* Missing LLM gateway / policy configuration on staging
* Missing content plan or methodology prerequisites

## Steps to reproduce

```bash
MAESTRO_CREDENTIAL_STORE=file maestro headless call posts.generate \
  --json '{"topic":"test"}' \
  --client "new-user-wjw6sreq/malaika-test" \
  --idempotency-key "test-post-1"
```

## Related

* Persona activation (`draft` → `active`) is not available as a headless surface or CLI operation
