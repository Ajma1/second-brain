## Bug

When navigating to Lead magnets with no projects created, the page renders completely blank — no sidebar content, no empty state message, no guidance on what to do next.

**Expected:** Empty state component (`LeadMagnetDocEmptyState`) should render with a "No lead magnets yet" message and instructions. Sidebar should indicate why the list is empty.

**Actual:** Blank white page with only the navigation sidebar visible.

**Root cause candidates:**

1. `LeadMagnetDocEmptyState` exists in `lead-magnets-empty-state.tsx` but may not be mounting
2. Sidebar's `LeadMagnetProjectGroups` maps over empty array and renders nothing — no fallback empty state in sidebar
3. Lead magnet creation requires "approved opportunities" from an LLM workflow — without those, users have no path forward and no explanation

* `apps/web/src/features/lead-magnets/lead-magnets-workspace-parts.tsx` (sidebar)
