## Goal

Build the pure TypeScript contracts that every later graph, scoring, privacy, budget, and evaluation stage depends on.

## Files

Create:

* `tooling/corpus/beneficial-adjacency/privacy.mts`
* `tooling/corpus/beneficial-adjacency/scoring-contract.mts`
* `tooling/corpus/beneficial-adjacency/budget-ledger.mts`
* `tooling/corpus/beneficial-adjacency/eval-harness.mts`

Modify:

* `tooling/corpus/linkedin-beneficial-adjacency.test.mts`

## Work

Add tests first, then implement:

* Canonical LinkedIn URL normalization.
* `actorKeyFor` priority order: profile ID, canonical LinkedIn URL, public identifier, salted fingerprint.
* Default redaction of raw actor names/headlines/company/profile URLs.
* Score composition with named components, penalties, `scoring_version`, `suggested_action`, `known_limitations`, bounded finite confidence.
* Budget ledger that aborts before provider calls when expected requests, tokens, or USD exceed caps.
* Negative controls and adversarial checks for self-edges, reversed duplicates, evidence-less high-confidence rows, and confidence cap violations.

## Constraints

* Confidence is capped at `0.95` in the first slice.
* Provider-touching stages must fail closed before making calls when over budget.
* Default artifacts must not expose raw third-party actor display fields.
* Use `host-test-slot` for test commands.

## Verification

Run:

```bash
rtk env HOST_TEST_MAX_LOAD_1M=100 host-test-slot --class focused pnpm exec tsx --test tooling/corpus/linkedin-beneficial-adjacency.test.mts
```

Expected: PASS after implementation.

## Acceptance Criteria

* Pure contract tests cover privacy, scoring, budget, and eval behavior.
* Over-budget tests prove provider functions are not called.
* Invalid scores and unsafe high-confidence rows throw deterministically.
