# [EPIC] Policy store — kill all hardcoded policy, make rules runtime-data

- **Identifier:** MAE-300
- **Status:** Done
- **Assignee:** Tim Keen
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-300/epic-policy-store-kill-all-hardcoded-policy-make-rules-runtime-data

Tim's directive: "The code should be so dumb. Don't do anything inline. If you need to make a decision, shell out to a variable, an algorithm, or an AI." Doctrine + blocking gate shipped in PR #36 (docs/product/policy-is-data.md). This epic removes the existing hardcoded policy and builds the runtime-modifiable store.

## Phase 1 — mechanical gate + separate data from logic

* `maestro/no-inline-policy-data` eslint rule (flags top-level value-consts / lists in logic layers; `// mechanism:` escape; config/ allowed) + adversarial RuleTester + config-drift pin + rule-coverage row.
* Create the `config/` layer (data separated from logic) and migrate every instance below into it; engines import policy from config/ or take it as a param (stay pure).

### The 18 instances found (full-tree audit 2026-06-12), classified:

**POLICY → must become data:**

* `checks/contentRules.ts:133` DEFAULT_CONTENT_RULES (rule catalog)
* `checks/contentLint.ts:70` HOLLOW_OPENER_SOURCE (cliché vocab), :65 ALL_CAPS threshold(3), :132 MAX_EXCERPT(120)
* `domain/batch.ts:22` LINKEDIN_DEFAULT_BATCH_SIZE(14), :25 MAX_BATCH_SIZE(30)
* `capabilities/inventory.ts:24` DEFAULT_CADENCE_PER_DAY(1), :31 RELEVANT_STATUSES, :40 INVENTORY_READ_CAP(500)
* `checks/slug.ts:7` MAX_SLUG_LENGTH(72)
* `agents/intent.ts:15` **MODEL = "anthropic/claude-haiku-4-5"** (hardcoded model id — also violates OpenRouter-from-config), :17 SYSTEM_PROMPT (prompts are versioned data → prompt registry), :14 INTENT_PROMPT_VERSION

**MECHANISM →** `// mechanism:` **escape (verify each):**

* `checks/slug.ts:6` SLUG_PATTERN, `contentLint.ts:57` URL_RE, :61 REGEX_ESCAPE_RE
* `checks/workspaceRole.ts:14` WORKSPACE_ROLES, `checks/intent.ts:8` INTENTS (closed domain vocabularies / types — confirm)
* `agents/intent.eval.ts:17` INTENT_EVAL_CASES (eval fixtures — allow like tests)

## Phase 2 — the runtime store (makes it modifiable WITHOUT a deploy)

* Convex `policies` table (scope system/workspace/customer/individual, locale, kind, data, source seed/human/learned) + `domain/policy.resolve()` + seed + capabilities to edit. "Add 20 phrases" = inserts; "French tomorrow" = locale rows; performance updates = learned rows. config/ modules become the seed loaded into the store.
