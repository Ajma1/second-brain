# [E1-8.1] Notion/Airtable sync — connection + stable-id mapping schema + capabilities

- **Identifier:** MAE-348
- **Status:** In Progress
- **Assignee:** Tim Keen
- **Team:** MAE
- **Updated:** 2026-06-26
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-348/e1-81-notionairtable-sync-connection-stable-id-mapping-schema

Backend-only first slice of MAE-246.

## Scope

Stable post-id mapping + connection schema + sync-direction policy for Notion/Airtable.

**In scope (this PR):**

* `schema/externalConnections.ts` — per-workspace connection (kind, encryptedAuthBlob, targetIdentifier, direction, status).
* `schema/externalPieceMappings.ts` — stable id mapping between pieces and external destinations.
* `capabilities/externalConnections.ts` — `connect`, `list`, `revoke` (admin-gated).
* `capabilities/externalPieceMappings.ts` — `getStableExternalId` internal query.
* `adapters/errors.ts` — add `EXTERNAL_CONNECTION_NOT_FOUND`, `EXTERNAL_MAPPING_NOT_FOUND`, `EXTERNAL_CONNECTION_REVOKED`.

**Out of scope (later PRs):**

* Real Notion/Airtable API calls (PR-2).
* Webhook handlers (PR-3).
* UI surface.
* Sealed-box encryption adapter (PR-2 placeholder; field is `v.string()` for now).

## Constraints

* `args+returns` validators. ConvexError-from-enum.
* WorkOS auth via `workspaceMutation`/`workspaceQuery` wrappers — no caller-supplied identity.
* Inject `now` (no ambient time in logic).
* No `v.any()`. No suppressions. ≤300 LOC.
