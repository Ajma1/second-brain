# Add CLI command for agent feedback

- **Identifier:** MAE-461
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-07-06
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-461/add-cli-command-for-agent-feedback

## Context

During alpha onboarding planning, we discussed a lightweight CLI command agents can use to send product/process feedback to the team after completing work.

This should not block alpha onboarding. It is a follow-up so we do not lose the idea.

## Desired shape

Add a real Maestro CLI command, likely under `pnpm maestro feedback`, that accepts a short summary, optional context/artifact path, and severity.

Example:

```bash
pnpm maestro feedback --summary "Importer manifest confused source context with draft posts" --context artifacts/onboarding/... --severity note
```

## Product direction

Eventually this feedback should land in Maestro's own product Brain or a small durable product-feedback store, not broad operational agent memory. Linear is only the temporary tracker for the first implementation.

## Acceptance

* CLI command exists as a real Maestro command, not a one-off script.
* Feedback is stored somewhere durable and queryable by the team.
* Command redacts secrets and does not upload raw customer context unless explicitly attached.
* Agents can be prompted to run it after significant CLI/onboarding work.
