# [ACPF-3] Background onboarding workflow with status and retries

- **Identifier:** MAE-311
- **Status:** Done
- **Assignee:** Tim Keen
- **Team:** MAE
- **Updated:** 2026-06-25
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-311/acpf-3-background-onboarding-workflow-with-status-and-retries

## Goal

Create the client onboarding workflow that runs Harvest intake in the background and only triggers idea generation after the intake finishes.

## Scope

* Implement `startClientOnboarding` workflow.
* Create client persona immediately, then start Harvest intake asynchronously.
* Fetch profile, posts, and comments/replies for the initial one-year window.
* Store source artifacts and normalized summaries.
* Track status transitions: created, harvesting, summarizing, generating_ideas, completed, failed.
* Persist retryable errors and run logs.
* Provide capabilities for UI/CLI/admin to inspect onboarding status.

## Acceptance

* Client creation does not block on Harvest completion.
* Idea generation does not start until Harvest intake is complete.
* Failed runs can be diagnosed from admin and retried safely.
* Tests cover success, partial Harvest failure, and retry behavior.
