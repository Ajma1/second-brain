## 2026-05-21 Update

Temporal Nexus is parked as a fallback/reference pattern. Convex is the v0 product runtime unless hardening fails.

## Scope

* Mine Nexus concepts only where they improve typed capability boundaries.
* Do not introduce Temporal as required infrastructure for the v0 runtime.
* Prefer Convex public/internal functions, components, workflows, and workpool contracts for implementation.

## Docs

* `docs/operator/decisions/ADR-2026-05-21-content-generation-workflow-runtime.md`
* `docs/operator/guides/convex-runtime-migration-guide.md`

## Acceptance Criteria

* Any retained Nexus learning is documented as fallback/reference material.
* Convex contracts remain the implementation target.
* No new architecture dependency on Temporal Nexus is created.
