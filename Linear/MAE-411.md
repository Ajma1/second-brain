## Goal

Classify LinkedIn hooks deterministically into useful multi-label features for template mining, lead magnet handling, and corpus analysis.

## Files

Create:

* `tooling/corpus/beneficial-adjacency/hook-classifier.mts`

Modify:

* `tooling/corpus/linkedin-beneficial-adjacency.test.mts`
* `tooling/corpus/linkedin-corpus-analytics.mts`
* `tooling/corpus/linkedin-corpus-analytics.test.mts`

## Work

Implement `classifyHook(text)` with primary hook type, secondary hook types, confidence, specificity/tension/proof/curiosity/moment scores, copy-risk, lead-magnet flag, and a `seeMoreReason`.

Required hook classes include moment-in-time, controversial statement, proof statement, question/challenge, mistake/confession, process teardown, list/framework, contrarian lesson, personal story setup, specific observation, audience callout, lead magnet CTA, plain status update, weak/unclear.

Wire analytics report headers so template candidate exports include `secondary_hook_types` and `curiosity_gap_score` without removing existing hook fields.

## Constraints

* Lead magnet posts are useful but must be classified distinctly from organic template candidates.
* Deterministic rules are acceptable for this slice; keep it eval-ready.
* Do not make templates rigidly lock user voice later; the goal here is feature capture.
