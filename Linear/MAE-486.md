# bug: active personas disappear from Research & Voice dashboard

- **Identifier:** MAE-486
- **Status:** Done
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-08-01
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-486/bug-active-personas-disappear-from-research-and-voice-dashboard

## Problem

When a persona's status is changed from `draft` to `active`, it disappears from the Research & Voice persona list. The dashboard only shows draft personas — there is no filter or tab to view active ones.

**Screenshot:** The persona list shows Susan Hansted (draft), Shelley Riutta (draft), and Malaika (draft). Tim Keen was changed to `active` and is no longer visible.

## Root cause

`clients-dashboard-adapter.ts:224` calls `listClientPersonas` with no `status` argument. The backend defaults to `CLIENT_PERSONA_STATUSES[0]` which is `"draft"` (`profiles.ts:36,84`). Active personas are filtered out by the query.

```typescript
// profiles.ts:84
const status = args.status ?? DEFAULT_LIST_STATUS; // defaults to "draft"
const rows = await ctx.db.query("clientPersonas")
  .withIndex("by_workspace_status_updated_at", (q) =>
    q.eq("workspaceId", ctx.workspace._id).eq("status", status))
```

## Expected behavior

The persona list should show both `draft` and `active` personas, or provide a filter/tab to switch between them. Active personas should not silently vanish.

## Impact

* Users who activate a persona lose access to it in the UI
* The activation flow (which is already not exposed as a headless surface) effectively breaks the persona view
* Workaround: change status back to `draft` in the Convex dashboard

## Files

* `packages/convex/convex/capabilities/clients/profiles.ts:36,84` — default status filter
* `apps/web/src/features/clients/clients-dashboard-adapter.ts:224` — no status arg passed
