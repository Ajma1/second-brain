# [ACPF-7] First-week drafting workflow for selected 7 ideas

- **Identifier:** MAE-315
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-315/acpf-7-first-week-drafting-workflow-for-selected-7-ideas

## Goal

Create the workflow that turns 7 selected ideas into 7 LinkedIn text-only draft posts.

## Scope

* Implement `draftPostFromIdea` and `draftPostsFromSelectedIdeas` capabilities.
* Agency selects 7 ideas from the client idea bank.
* Workflow resolves agency methodology policy areas, client overrides, client voice/persona summaries, and market intelligence reads.
* Generate 7 text-only LinkedIn post drafts.
* Persist draft run metadata, idea references, evidence references, and draft text.
* Move drafts into the review/approval lifecycle.

## Acceptance

* Drafting is triggered from selected ideas, not from a hidden one-off prompt.
* Each draft links back to its idea and evidence.
* Workflow can be invoked from UI and CLI.
