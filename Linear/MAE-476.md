# Launch autonomous weekly good-post recommendations for every customer

- **Identifier:** MAE-476
- **Status:** Backlog
- **Assignee:** Tim Keen
- **Team:** MAE
- **Updated:** 2026-07-13
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-476/launch-autonomous-weekly-good-post-recommendations-for-every-customer

## Outcome

Every connected LinkedIn profile receives 2–3 current, safe, customer-fit reference posts each week without operator intervention. Customers can adapt a recommendation into a draft, retry or iterate it, return to the durable handoff, and give feedback. The CMO consumes the same canonical recommendations and evidence.

## Scope

* Automatic LinkedIn profile capture, validation, activation, and retry
* Shared reviewed corpus bootstrap plus leased autonomous refresh
* Truthful human-reviewed vs automatic-policy eligibility
* Safety, diversity, customer-fit ranking, and feedback/outcome learning
* Deterministic workspace runs, pinned policy values, provider budgets, dry-run, and fleet fault isolation
* Atomic staged materialization, CAS activation, previous pointer, and rollback
* Canonical serving to Inspiration, Home, Posts, weekly plan, and CMO tools
* Durable draft lineage, retry, intentional iteration, handoff, and feedback hydration
* Health, lifecycle telemetry, alerts, Buildkite schedule, migration, and staging lifecycle smoke

## Acceptance

* 2–3 creator-diverse recommendations for each eligible active LinkedIn profile
* No recurring operator approval; shared corpus and customer rankings update automatically
* UI and CMO recommendation IDs/order/evidence remain in parity
* Feedback changes the subsequent managed ranking cycle
* Provider cost/retry caps are pinned and enforced; failures are durably terminalized
* Dry-run is write-free and spend-free
* Rollback preserves active/previous pointers, lineage, drafts, and feedback
* Exact-SHA staging smoke proves profile → corpus → recommendations → draft → feedback → next set → rollback
* Production activation remains disabled until shadow, internal canary, and one autonomous scheduled cycle are proven
