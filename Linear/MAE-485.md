# bug: org-scoped API key creation unavailable for org owners

- **Identifier:** MAE-485
- **Status:** Done
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-08-01
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-485/bug-org-scoped-api-key-creation-unavailable-for-org-owners

## Problem

On the Settings → CLI & MCP page, the "Organization" scope button and "Custom" access preset are not clickable for a user who is `owner` on the organization.

## Investigation

The UI code at `api-keys-adapter.ts:175-182` correctly calls `organizationRoleAtLeast(membership.role, "admin")`, and `owner` (rank 2) >= `admin` (rank 1) returns true. The data is correct:

* Organization `mn7fey9v286efvr9hgbwjmfebd89716z` exists
* User `nh74n8ceyv35e3...` has role `owner` in `organizationMembers`
* `listMyOrganizations` returns the org with `role: "owner"`
* Workspace `organizationId` matches

The buttons should be enabled but aren't. Possible client-side rendering issue — the query data may not be loading in time, or there's a conditional path not covered.

## Impact

Without org-scoped API keys, workspace provisioning via CLI (`access.alphaWorkspaces.create`) is blocked — it requires an org-level API key principal.

## Steps to reproduce

1. Log in as org owner on staging
2. Go to Settings → CLI & MCP
3. Observe "Organization" scope and "Custom" preset are greyed out

## Workaround

None currently. Workspace provisioning requires the `/onboarding` UI (also disabled) or direct Convex dashboard access.
