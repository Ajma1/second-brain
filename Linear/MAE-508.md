# P1: CLI GitHub/Homebrew channels lag the released npm package

- **Identifier:** MAE-508
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-08-01
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-508/p1-cli-githubhomebrew-channels-lag-the-released-npm-package

## Environment and SHA

* Released CLI under test: `0.3.0`, tag commit `61c8ed2a734693bde06829e263f8a47eea79996b`
* Tested source/docs: `95c9a04c048dcf8806bd754ccc606225b4314e5b`
* Hosts: unauthenticated `curl` on controller and clean Linux `maestro-worker`

## Minimal reproduction

```sh
curl -fL -o maestro-cli.tar.gz \
  https://github.com/modernagencysales/maestro/releases/download/maestro-cli-v0.3.0/maestro-cli-v0.3.0-linux-x64.tar.gz
gh release list --repo modernagencysales/maestro-cli-releases
gh api repos/modernagencysales/homebrew-tap/contents/Formula/maestro-cli.rb
npm install @maestrogtm/maestro-cli@0.3.0
```

## Expected

Launch docs identify working primary GitHub Releases and Homebrew channels for the current CLI. An unauthenticated user can download the current asset, and Homebrew installs the current supported version. Documentation accurately describes npm's release status.

## Actual

* Unauthenticated download of the `0.3.0` asset from the private `modernagencysales/maestro` release fails (`curl` exit 56).
* The public `modernagencysales/maestro-cli-releases` mirror contains only `0.1.1`, while current install docs construct mirror URLs for arbitrary current versions.
* The public Homebrew formula is pinned to `0.1.1` and URLs under the public mirror.
* npm `@maestrogtm/maestro-cli@0.3.0` installs successfully from a clean environment, while current docs still label npm deferred.

## Suspected boundary

Release publication/mirroring, Homebrew formula promotion, and launch documentation synchronization. No unverified root cause is claimed.

## Severity and launch impact

**P1 / distribution blocker.** The channels documented as launch-supported do not deliver the current CLI to an unauthenticated user, while the working npm channel is documented as deferred.
