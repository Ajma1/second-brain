## Bug

There is no way in the UI to change a client persona's status from "draft" to "active". Personas are created in "draft" status (`CLIENT_PERSONA_STATUSES[0]` = "draft") and stay there permanently unless manually changed in the database.

**Impact:** Active status matters — workflows, the CMO agent, and dashboard queries filter by status. A persona stuck in "draft" may not be detected by generation workflows, research pipelines, or the sidebar clients rail (which queries by status).

**Expected:** The client settings or persona detail page should have a way to activate a persona (e.g., a status toggle, an "Activate" button, or automatic activation after research completes).

**Actual:** No UI control exists. The only way to change status is via the Convex dashboard or a direct database mutation.

* `packages/convex/convex/schema/clientPersonas.ts` — status: "draft" | "active" | "archived"
* `packages/convex/convex/capabilities/clients/profiles.ts` — `DEFAULT_LIST_STATUS = CLIENT_PERSONA_STATUSES[0]` ("draft") — default listing shows only drafts
* `packages/convex/convex/capabilities/clients/profiles.ts:140` — `updateClientPersona` mutation exists but no UI calls it to change status
