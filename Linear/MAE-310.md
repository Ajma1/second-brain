# [ACPF-2] Harvest adapter and source artifact storage

- **Identifier:** MAE-310
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-18
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-310/acpf-2-harvest-adapter-and-source-artifact-storage

## Goal

Create the Harvest integration foundation behind a server-side adapter and store raw source evidence with provenance.

## Scope

* Store/use a Maestro-admin-owned Harvest API key from Convex env.
* Normal API-key mode only.
* Implement small Harvest capabilities such as `fetchHarvestProfile`, `fetchHarvestProfilePosts`, and `fetchHarvestProfileComments`.
* Fetch one year of LinkedIn profile activity during initial intake.
* Capture profile, posts, and comments/replies as much as Harvest returns.
* Store source artifacts with type, source URL/profile URL, fetchedAt, date/time if identifiable, raw payload reference, normalized fields, and client persona ID.
* Record Harvest usage/errors for admin monitoring.

## Non-goals

* No custom LinkedIn cookies.
* No proxies.
* No user/session account handling.
* No agency-supplied Harvest credentials in v1.

## Acceptance

* Harvest calls never happen from React or CLI directly.
* Source artifacts can be traced back to the client persona and Harvest fetch run.
* Failures are persisted with retryable error details.
