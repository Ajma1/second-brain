# [ACPF-11] UI surfaces for onboarding, idea bank, drafting, and post Kanban

- **Identifier:** MAE-319
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-17
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-319/acpf-11-ui-surfaces-for-onboarding-idea-bank-drafting-and-post-kanban

## Goal

Build the agency UI surface for the v1 workflow using the same backend capabilities as the CLI.

## Scope

* Client onboarding screen with required client name and LinkedIn profile URL, plus optional fields.
* Onboarding/Harvest status view with errors and retry affordances.
* Client idea bank view with 20-30 generated ideas, evidence, confidence, and selection controls.
* Agency-wide idea search/filter across clients.
* First-week drafting view for selected 7 ideas.
* Post Kanban/status view for drafts, approved/ready, and scheduled posts.
* Basic admin entry points can link to the admin monitoring issue rather than duplicate it here.

## Acceptance

* The UI can run the full v1 workflow through backend capabilities.
* It does not call Harvest directly.
* It makes approved/ready and scheduled states clear without introducing client approval or changes-requested flow.
