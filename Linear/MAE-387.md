# As a user, I can visually compose workflows with drag-and-drop

- **Identifier:** MAE-387
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-22
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-387/as-a-user-i-can-visually-compose-workflows-with-drag-and-drop

Editor mode for the workflow canvas: drag nodes from a palette, wire edges between handles, set conditions and config inline, save to a template. Turns the read-only viewer into a full workflow builder for non-technical users composing GTM workflows.

## Acceptance criteria

* Node palette with all 9 node types, drag-to-add
* Edge wiring via React Flow handles (nodesConnectable=true)
* Inline config editing (condition expressions, capability refs, prompts)
* Save composed graph as a workflowTemplates entry
* Undo/redo support
* Validation: cycle detection, required fields, orphan node warnings
