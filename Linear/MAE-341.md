# [E1-2.8] Co-edit annotation propose/accept/reject capabilities

- **Identifier:** MAE-341
- **Status:** Done
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-19
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-341/e1-28-co-edit-annotation-proposeacceptreject-capabilities

PR-8 of the MAE-240 co-edit studio stack. Stacks on PR #215 (`feat/coedit-pending-styles-MAE-337`).

Adds annotation lifecycle write surface in `packages/convex/convex/capabilities/annotations.ts`:

* `proposeReplaceInternal` / `proposeReplace` — version-guarded insert with status "pending".
* `proposeInsertInternal` / `proposeInsert` — same for kind="insert".
* `proposeDeleteInternal` / `proposeDelete` — same for kind="delete".
* `accept` — version-guarded `prosemirrorSync.transform` + patches annotation status "accepted" + writes editEvent + records human edit via `capabilities/edits.recordEditInternal`.
* `reject` — patches annotation status "rejected" + writes editEvent.

Adds five new closed-enum ErrorCode entries:

* `ANNOTATION_NOT_FOUND`
* `ANNOTATION_ALREADY_RESOLVED`
* `ANNOTATION_VERSION_CONFLICT`
* `ANNOTATION_BLOCK_NOT_IN_DOCUMENT`
* `ANNOTATION_ANCHOR_OUT_OF_RANGE`

OUT OF SCOPE: `listPending` (PR-7 ships), `acceptAllByAuthor` (PR-9), agent-side propose tools (PR-10), workflow integration (PR-11).

~290 LOC.
