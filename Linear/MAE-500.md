# bug: pipeline idea creation has no persona picker — defaults to workspace owner

- **Identifier:** MAE-500
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-07-31
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-500/bug-pipeline-idea-creation-has-no-persona-picker-defaults-to-workspace

## Problem

When creating a new idea from the Pipeline (+ Idea button), there is no way to select which persona/client the post is for. The idea automatically gets attributed to "malaika" (the workspace owner) with no option to change it.

This means ghostwriters with multiple clients (e.g. Tim Keen, Susan Hansted, Shelley Riutta) in the same workspace cannot target a specific persona when creating content ideas.

## What happens

1. Click "+ Idea" in Pipeline
2. "New idea" dialog shows only: Idea title, Angle, Create idea button
3. No persona/client picker anywhere
4. Created idea shows "malaika · text" — hardcoded to workspace owner
5. Clicking the idea shows "Pipeline idea preview" with "Generate draft" button — still no persona picker
6. After "Generate draft" / "Save to drafts", post moves to Drafting column still attributed to "malaika"

## Root cause

`createPipelineIdeaRef` at `pipeline-discovery-refs.ts:98-114` only accepts `workspaceId`, `title`, `angle`, `requestKey` — no `clientPersonaId` parameter.

In `pipeline-discovery.commands.ts:32`, the clientId is hardcoded:

```typescript
clientId: UNATTRIBUTED_PIPELINE_CLIENT_ID, // empty string
```

## Expected behavior

The "New idea" dialog should include a persona picker dropdown listing all personas in the workspace (Tim Keen, Susan Hansted, Shelley Riutta, Malaika). The selected persona should be associated with the idea and carried through to draft generation.

## Impact

This is a core workflow gap for ghostwriters managing multiple clients. Every idea defaults to one persona, making the Pipeline unusable for multi-client content planning.

## Environment

* Staging: [staging.maestrogtm.com](<http://staging.maestrogtm.com>)
* Workspace: new-user-wjw6sreq/malaika-test (has 4 personas)
