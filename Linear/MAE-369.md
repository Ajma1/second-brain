Epic: typed directed-graph workflow definitions with a condition parser, topo-sort execution engine, durable interpreter, and a read-only React Flow canvas viewer.

## Backend (PRs #668–#677)

* WorkflowGraph Convex validators and domain types
* Condition expression parser (recursive descent, JS precedence)
* Topo sort, arg resolution, edge activation engine
* generatePostGraph builtin constant
* workflowTemplates table schema
* ESLint gate widening for interpreter files
* runGraph durable workflow interpreter

## Frontend (PRs #679–#684)

* @xyflow/react install + pure state module (graph-to-canvas conversion)
* 9 custom node-type components + smoke tests
* Data-flow edge + canvas surface (viewer mode)
* Convex adapter (builtin/inline sources)
* Route + screen at /_workspace/workflows
* Node detail panel with click-to-inspect

16 PRs total, stacked via Graphite. All zero-debt, 35 frontend tests + 66 backend tests.
