# Targeted connection requests for clients — GetSales first-class integration

- **Identifier:** MAE-358
- **Status:** Backlog
- **Assignee:** —
- **Team:** MAE
- **Updated:** 2026-06-20
- **URL:** https://linear.app/modern-agency-sales/issue/MAE-358/targeted-connection-requests-for-clients-getsales-first-class

## User Story

**As a LinkedIn ghostwriter, I want to send targeted connection requests to my clients' ideal prospects, so that content reaches the right audience and drives pipeline growth alongside the content strategy.**

## Source

Dalton Danks call (2026-06-18). Dalton already does connection request automations and considers it essential to content ROI.

> "your ideal client's like they're not going to come to you that you have to go to them"

## Scope

Connection request automation will NOT be built natively — it is against LinkedIn TOS and risks client account bans. Instead, integrate with **GetSales** as first-class partner (earlier stage, more customizable). HeyReach as alternative option.

## Gap from Existing Issues

[MAE-297](https://linear.app/modern-agency-sales/issue/MAE-297/e10-2-dm-sequences-and-cold-outreach-for-the-ghostwriters-own-client) (DM sequences & cold outreach) is scoped to the ghostwriter's own client acquisition (backlog only), not managing outbound for clients' accounts.

## Prior Art (reference for integration design, not code to port)

**mas-platform** (fully built natively — we are NOT replicating this approach):

* `trigger/poll-connection-requests.ts` — 20-min polling via Unipile, campaign lead status tracking
* `lib/types/linkedin-action-queue.ts` — 8 action types, priority system, operator boost
* `server/services/linkedin-action-executor.ts` — Unipile dispatch with sandbox mode
* Safety: 7-day rolling 100-connect cap, fairness service with round-robin, 10% random skip, circuit breakers
* **Design patterns worth adopting for GetSales integration:** action queue, safety caps, fairness/round-robin, campaign-lead status tracking

**maestro-v2-3**: Explicitly out of scope ("Not a LinkedIn automation tool"). Warm leads page has manual "Open LinkedIn" flow.

## Implementation Notes

Build a GetSales API integration that:

1. Syncs ICP-matched prospect lists from Maestro → GetSales campaigns
2. Pulls connection acceptance / reply status back into Maestro
3. Surfaces warm leads (accepted connection + engaged with content) for the ghostwriter to act on
4. Respects safety patterns from mas-platform: caps, pacing, do-not-engage lists

The content strategy (Maestro) + outbound strategy (GetSales) + engagement tracking should form a closed loop.
