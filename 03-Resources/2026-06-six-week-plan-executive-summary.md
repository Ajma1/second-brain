# What the six-week plan actually said

> **Status: SUPERSEDED (archived 2026-06-10).** This is the distilled intent of the
> aspirational MAE six-week plan (~175 issues) that the team did not work from. Kept for
> the *thinking*, not as current direction. Full issue transcript: `~/linear-archive-2026-06/issues.jsonl`.

## The thesis (Series anchor)
**Orchestration, applied by an expert.** A maestro isn't a switchboard — it's an expert
conductor applying real-time judgment to a complex, changing system. Maestro = the
orchestration layer for GTM, *built by orchestrated agents, in public*. Every workstream
ladders back to that story.

## The three tracks
1. **The Factory + Cockpit + Methodology build** (P1–P6, factory.* workflows 0.1–0.9, numbered 1–12).
   A Fabro-gated coding "factory" (draft-spec → review → architecture → work-packages →
   implement → code-review → simplify → release, each with evals) on Convex/Daytona; a
   grounded-node brain + claim schema; a campaign-generation runtime (objects, opt-in pages,
   Resend sending, funnel stats); the **Cockpit** app (generative shell, provenance/trace view,
   Tiptap+AI-toolkit editing); and an **edit-learning loop** (capture edits → distill → taste/defect
   router → eval-case promotion). This is the product spine.
2. **The MAS GTM Engine** (G0–G7). Dogfooding the product to run MAS's own GTM: G0 brain
   bootstrap (the "quarry map" of reusable patterns across mas-platform/maestro-os), G1 content
   (ideation→creation→5x/week→repurpose), G2 warm outbound, G3 lists + cold-email engine, G4
   nurture/trial/setup funnel, G5 ads, G6 ops + the constraint review, G7 the portable agent
   library + agent-builder agent.
3. **Launch & pricing** (L0–L3). Pricing model + BYOK-vs-managed mechanics, an Astro marketing
   site (SEO/GEO), a founding-partner program + recruiting funnel, staged founding-cohort →
   public launch.

## What to take forward
The *bets* are still live (orchestration POV; brain-grounded generation; edit-learning as the
moat; dogfood-MAS-GTM). The *issue decomposition* is not — it was push-structure nobody pulled
from. New work is now agent-native: created from Discord, triaged, delegated. See
`[[MAE — GTM Engine (G-series)]]`, `[[MAE — Factory, Cockpit & Methodology build]]`,
`[[MAE — Launch & pricing (L-series)]]`.
