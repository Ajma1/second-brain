# example.com

**TL;DR:** The example.com domain is reserved for use in documentation and examples, and should not be used in production environments.

## Key points
- example.com is intended for documentation and examples
- Using example.com does not require permission
- The domain should be avoided in operational use
- It is managed by IANA (Internet Assigned Numbers Authority)
