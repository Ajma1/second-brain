Implements the full attribution & versioning design (`docs/superpowers/specs/2026-06-09-attribution-versioning-design.md`, MAE-219 Slice 1) and generalizes the golden workflow to every content type, with iterating evals.

## What's in here (14 commits, all TDD'd, 374 tests green)

**Slice 1 — the fingerprint spine**
- `lib/attribution/`: canonical-JSON serializer + pure-JS sha256 (mutations have no crypto.subtle) + composable `methodologyHash = combine(voiceCoreHash, moduleHash)`
- Methodology doc restructured to `{ voiceCore, modules }` — voice edits transfer across every content type, module edits stay scoped (proven in tests)
- `contentObjects` generalized into the content-piece registry (kind, sourceRunId edge, denormalized fingerprint), generic `outcomes` ledger, append-only `methodologyVersions` registry
- `acceptRun` review→publish bridge; edit-at-accept = first human_edit w/ normalized-Levenshtein magnitude; `methodologyPerformance.byHash` (pooled, min-n gated, directional)
- Frozen judges per type, pinned by CI snapshot hash — never optimization targets

**Seven content workflows on a shared skeleton** (`lib/contentWorkflow.ts`)
posts · emails · carousels · landing pages · thank-you pages · lead magnets · image posts — deliberately different shapes (best-of-N, one-shot sequence, brief→parallel sections, outline→sections, concept→caption). Multi-kind ReviewQueue in the client cockpit.

**Improvement lab** (`scripts/improvementLab.mjs`)
Real workflows generate K assets → Sonnet critic (never the frozen judge; Goodhart-guarded) → ZFC module patch (shape-whitelisted) → new methodologyHash → regenerate → before/after report. Live rounds: email critic 4.20→5.40→5.60; landing 5.13→5.60; thank-you 6.33→6.73 + vision 4.33→6.67.

**Visual eval loop + notion-kit previews**
`/p/$workflowId` public route renders generated pages with the real notion-kit components (CockpitPage shell). Steel screenshots the deployed page → vision judge with a designer-grade bar (Notion/Linear ship-quality; template-grade caps at 6) + `designNotes` channel. Caught real bugs: scaffold leak (3/10 render), buried booking CTA.
