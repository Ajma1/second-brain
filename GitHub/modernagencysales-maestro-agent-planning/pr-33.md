# Carousel & infographic engine (MVP backend): post → on-brand carousel, rendered in Convex

PR #33 in modernagencysales/maestro-agent-planning — closed — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/33](https://github.com/modernagencysales/maestro-agent-planning/pull/33)

## What this is

An **agent-editable carousel/infographic engine** built into `maestro-v2-shell-spike` — the "AI Design Loop" from our Paper build, reproduced **inside the product** (no paper.design dependency, no headless browser). Turn an existing post (`contentObject`) into an on-brand carousel: generate freeform HTML slides → render to PNG in Convex → brand-lint + fix loop → export combined PDF. Humans/agents *talk*; the agent mutates the deck. No visual editor.

**Spec:** `docs/superpowers/specs/2026-06-03-carousel-infographic-engine-design.md`
**Plan:** `docs/superpowers/plans/2026-06-03-carousel-infographic-engine.md`

## What's built (Tasks 1–12, all TDD)

- **Render (pure JS+WASM, Convex-bundlable):** `convex/render/` — `brandLint`, `fonts` (Inter WOFF, base64-embedded), `renderSlide` (Satori + **resvg-wasm** → PNG), `buildPdf` (pdf-lib), `prompts`.
- **Data:** `brandKits` table + CRUD; carousel = existing `contentObject` (`assetType:"carousel"`), slides = `assetSections` (+ optional render fields); `carouselRuns`/`carouselEvents` for the run + live event stream.
- **Ops (one surface = agent tools + UI + future MCP):** `generateFromPost`, the render→brand-lint→fix loop (`renderRun`), `exportPdf`, `regenerateSlide`/`editRegion`/`reorderSlides`/`setBrand`, plus `getCarousel`/`getRunEvents` reads.

## Key decisions surfaced during build

- **resvg-wasm, not resvg-js** — the native `.node` binary can't be bundled by Convex; the WASM build can. This was the renderer feasibility gate; it's cleared.
- **Brand-lint is deterministic** (only possible because brand lives in code) — the cheap reliability win + edge over image-gen tools.
- Render util captures the **real `fetch`** at module load so tests can stub `fetch` for LLM mocks without breaking wasm init.
