# fix(partners): open up design-partner qualification gate

PR #43 in modernagencysales/maestro-agent-planning — closed — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/43](https://github.com/modernagencysales/maestro-agent-planning/pull/43)

## What

Loosens the design-partner booking gate (`/partners`) so we stop auto-rejecting good applicants. Picked the **2-of-3** level.

### Why
Reported: lots of **solo founders** and **all teams** were getting denied. Root cause in `convex/lib/qualifyPartner.ts`:
- **Teams**: hard-returned `team_not_yet` on every submission — 100% denied.
- **Solo**: required clearing **all three** axes at once (cadence AND tenure AND audience), so a serious newer founder, an occasional poster, or a sub-1k operator got cut.

### Changes
- **Teams now qualify** (like agencies). The form collects no team-specific fields to bar on, and the program explicitly invites larger orgs.
- **Solo is now 2-of-3** across cadence / tenure / audience, each floor lowered one notch:
  - cadence: + `occasionally` (only `rarely` fails)
  - tenure: + `3–6mo` (only `<3mo` fails)
  - audience: + `500–1k` followers (or pays for tools)
- Only genuine non-starters (≤1 axis cleared) still deflect with `solo_below_bar`.

### Who flips denied → qualified
- Newer founder posting daily, 3 months in, small audience → in (cadence + tenure).
- Occasional poster with a year of tenure → in.
- Sub-1k founder posting daily → in (cadence + audience).

### Tests
