Slice 2 of the attribution & versioning design (MAE-222): **where claims become causal.**

## Randomized module experiments (in-Convex, live now)
- `experiments` table: one running experiment per (methodologyKey, workflowType) — a candidate module (e.g. an improvement-lab proposal) vs the live module, pooled across every owner on the key
- **Per-piece randomization at resolveContext**: deterministic sha256(workflowId:experimentId) 50/50, replay-safe; the arm rides in the fingerprint (`experimentId`, `variant`); variant runs *resolve with* the candidate module so generation always matches the stamp
- `experiments.results`: honest readout — min-n per arm, 95% CI on the edit-rate difference, **causal language only when the CI excludes zero**; under-powered → "Not enough data yet", never a point estimate
- `experiments.promote`: human-gated rollout to every owner (output-affecting modules are never auto-promoted)
- Fixed a latent stamp/generation mismatch: postWriting now consumes resolveSpine's returned doc

## PostHog mirror (activates when a key is set)
`$ai_generation` per run (trace id = workflowId) + `piece_accepted` + `human_edit`, all with full fingerprint props. Scheduled fire-and-forget, **gated on `POSTHOG_API_KEY`** (no key → zero scheduled jobs), fail-soft. Convex stays the system of record; the product never reads numbers back from PostHog.

**To activate the mirror:** `npx convex env set POSTHOG_API_KEY phc_…` (+ optional `POSTHOG_HOST` for EU). No deploy needed.
