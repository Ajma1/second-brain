# Brain + onboarding — readable Brain page, source provenance, lead magnet funnel

PR #28 in modernagencysales/maestro-agent-planning — closed — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/28](https://github.com/modernagencysales/maestro-agent-planning/pull/28)

## Summary
Bundled iteration so onboarding teaches the whole product (Brain + lead magnets), not just posts — and so the Brain page is actually usable.

### 1. New \`/brain\` page (replaced the unusable one)
The old page was the thing you flagged. Rebuilt around **what facts the system knows + where each came from + whether it's been used** — not an empty taxonomy.
- Stats: facts · sources · cited-in-posts · avg confidence
- \"recently learned\" strip
- Source filter chips (LinkedIn / website / posts / voice)
- Card grid — each fact shows: source pill (click → origin), confidence dots, **\"used N×\"** citation counter

Deliberately **no radial graph.** Pressmaster's radial is a pretty taxonomy with nothing in it; at scale it's a hairball. Their category labels become our *filters*, not the main view. Cards beat graphs for daily use.

### 2. Source provenance on brain nodes
- Added optional \`sourceLabel\` + \`sourceUri\` to \`groundedNodes\` (+ \`nodeView\`).
- Synthesis now attributes each fact to its origin (model picks LinkedIn / website / posts). **Verified e2e** — facts came back tagged \`LinkedIn profile\` / \`your website\` / \`recent posts\` with deep-link URIs.

### 3. Lead magnet funnel seeded during onboarding
The wow you asked for — not just a quiz, a whole funnel.
- One Haiku call drafts: title, promise, 5 quiz questions, 3 result archetypes, thank-you copy, **3-email sequence**.
- Seeded as a real \`funnel\` + \`opt_in\`/\`scorecard_result\` stages + sections (rendered by the existing studio). Email sequence stored on \`funnelAssets\`.
- 2nd inbox ask \"your first lead magnet is ready\" deep-links to the funnel studio (Talk Mode AskRow now honors \`payload.route\`).
- **Verified e2e** — created \"What's Slowing Down Your Ad Launches?\" tailored to AdManage.

### 4. Onboarding Brain chapter
On completion, a \"your Brain just started\" card lists the 4 facts with source tags + a link to \`/brain\`, teaching the grounding concept before redirect.

## Honest limitations
- **Usage counts (\"used N×\") read real \`citationCount\`** but seed data mostly has 0, so new onboarding facts show \"not used yet.\" Real backfill of post→fact citations is later work.
- **Email sequence has no dedicated renderer** in the funnel studio yet — it's persisted on \`funnelAssets\` but the studio won't show it nicely. The inbox ask still truthfully says \"3 follow-up emails.\"
- **Brain chapter is teach-not-animate.** Facts already appeared one-by-one during the synth phase; the chapter is the explainer card, not a second animation. Kept restrained on purpose.
