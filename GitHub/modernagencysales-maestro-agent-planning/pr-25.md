# Live onboarding — the first call (real APIs, ~25s end-to-end)

PR #25 in modernagencysales/maestro-agent-planning — closed — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/25](https://github.com/modernagencysales/maestro-agent-planning/pull/25)

## Summary
Replaces the static 5-phase backfilled \`/onboarding\` with a **live agentic first-touch flow**. User pastes a LinkedIn URL (+ optional website), Sandra runs three real scrape lanes in parallel, synthesizes their voice with Claude, drafts their first post — all visible in real-time, all wired to real APIs.

End state: drop into \`/talk\` with the draft in hand. The product is **already useful** at minute 1 — this is the Pressmaster gap.

## Backend
- **Schema:** \`onboardingRuns\` + \`onboardingEvents\` tables.
- **\`onboardingLive.start\`:** kicks 3 parallel internal actions — \`runHarvestProfile\` (HarvestAPI), \`runHarvestPosts\` (HarvestAPI), \`runWebsiteExtract\` (Parallel.ai Extract). Each writes events as it progresses (“crawling X” → “received in 4.8s” → indented sub-step lines).
- **Orchestrator:** \`checkAndAdvance\` self-polls every 1.2s; once all lanes settle, runs \`runSynthesis\` (Haiku → 4 brain facts as events) then \`runDraftPost\` (Haiku → JSON title+body, typewriter-streamed into run fields).
- **All LLM calls via OpenRouter** per project standards.
- **Env (Convex deployment):** \`HARVEST_API_KEY\`, \`PARALLEL_API_KEY\`, \`OPENROUTER_API_KEY\`. Model defaults to \`anthropic/claude-haiku-4-5\`; swappable per run via \`model\` arg (A/B with DeepSeek a one-line change).

## UI
- **\`OnboardingShell\`:** reuses Talk Mode's PhoneChat on the left so Sandra narrates throughout.
- **\`UrlInput\`:** one required LinkedIn field + optional \"+ add website\" toggle. Defaults seeded to Raphael for one-click demoing.
- **\`LiveAgentFeed\`:** Claude-turns-style lane sections (profile / posts / website / synth / draft) with active/done/error status badges, indented sub-step events, animated brain-fact chips after synthesis.
- **\`DraftReveal\`:** LinkedInPreview that fills in as the draft streams, \"open Talk Mode\" CTA on complete, auto-redirects to \`/talk\` after 4.5s.

## Tradeoffs / things to know
- **Typewriter is post-hoc, not token-streaming.** The Haiku call returns full JSON, then the UI animates the reveal by patching \`draftBody\` in chunks every 45ms. Looks streamed; isn't. Real token streaming (SSE through Convex action) is doable but adds complexity I skipped for the prototype.
- **Profile cold-call is the bottleneck** (~18s). Harvest caches aggressively, so re-running the same URL completes in ~10s. Demos are fine; first-touch real users hit the cold path.
- **No \"seed inbox+calendar with extra posts\"** wired yet — the post-onboarding Talk Mode state is whatever already exists for the dev user. Adding 4 background-generated posts during onboarding is a fast follow if you want the calendar pre-populated for new accounts.
