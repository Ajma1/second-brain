# Onboarding — live completion panel, drop auto-redirect

PR #30 in modernagencysales/maestro-agent-planning — closed — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/30](https://github.com/modernagencysales/maestro-agent-planning/pull/30)

## Summary
You flagged: \"it rapidly redirects\" + \"i thought we added some stuff around deeper things.\" Both are the same issue — the auto-redirect was firing before the async higher-order synthesis (positions / opportunities / gaps / lead-magnet funnel) finished, and the completion view never surfaced any of it.

## Changes
- **Drop the 6.5s auto-redirect.** Completion is a destination; user clicks \"open Talk Mode\" when ready.
- **Live CompleteCTA** — queries \`assetIntelligenceOverview\`, \`contentObjects\`, \`cmoAsks\`, \`funnels\` filtered to \`_creationTime > run.startedAt\`, so it shows only what *this* run produced (not dev-user seed data).
- 7 rows turn from ⟳ → ✓ as each piece lands:
  - brain facts
  - **positions synthesized** ← the deeper thing
  - **opportunities mapped** ← the deeper thing
  - **gaps identified** ← the deeper thing
  - calendar drafts
  - inbox asks
  - lead-magnet funnel
- Bottom actions: primary \"open Talk Mode\", secondaries \"see synthesis in /brain\" and \"open your funnel\" (latter unlocks when the funnel lands).
