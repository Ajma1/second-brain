# LinkedIn Scout (research) agent — spike + durable live workflow

PR #35 in modernagencysales/maestro-agent-planning — closed — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/35](https://github.com/modernagencysales/maestro-agent-planning/pull/35)

## Summary

Adds the **Scout** agent to the LinkedIn content team: an external-intelligence agent (distinct from the Brain/Topic-Intelligence researcher) that crawls the LinkedIn **engagement graph**, detects **follower-normalized outliers**, model-extracts **reusable creator-agnostic format shapes** (ZFC via OpenRouter), dedup-merges a **Format Library**, scores stated **platform insights** with measured-wins skepticism, and emits **repurpose-opportunity handoffs** to the Writer. It is walled off from the grounded Brain.

Built in two stages in `prototypes/convex-runtime-bakeoff`:

**1. Spike — the loop (12 TDD tasks).** Pure libs (`scoutHarvest`, `scoutBaseline`, `scoutFormat`, `scoutExtraction`, `scoutBudget`), tenant-scoped handlers (`scout.ts`), and an in-memory `runScoutCycleCore` orchestrator proving one crawl lap + one engagement-graph hop with a budget kill-switch. Self-contained → ported cleanly onto `main`'s schema.

**2. Live durable workflow (7 TDD tasks).** Wires it to run end-to-end against **live HarvestAPI + OpenRouter** via a durable `@convex-dev/workflow` — the **canonical execution pattern** for the agent system. The workflow handler is the orchestration (I/O in `step.runAction`, DB in `step.runMutation`), reusing the tested composite handlers (`scoutCycle.ts`). Includes a live smoke script to judge extraction quality.

Specs + plans under `docs/superpowers/`.

## Key invariants (verified)
- **Brain-wall:** Scout only writes `scout*` tables — never Brain/knowledge/topic.
- **ZFC + OpenRouter:** all semantic judgment is a model call via OpenRouter; deterministic `detectShape` is only a prompt hint. No direct provider APIs, no new deps.
- **Workflow determinism:** no `Date.now`/`Math.random` in the handler body; `now` fixed once in the kickoff mutation.
- **Convex isolate typecheck:** env read via a typed `globalThis` accessor (no bare `process`); `convex dev --once` reaches "functions ready".
