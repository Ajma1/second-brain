# The Replacer — deterministic lint + semantic editor

PR #44 in modernagencysales/maestro-agent-planning — open — by kimprobably — [https://github.com/modernagencysales/maestro-agent-planning/pull/44](https://github.com/modernagencysales/maestro-agent-planning/pull/44)

## What this is

The **replacer** — takes a generated post and returns a clean one (or flags what it can't fix). Two honestly-labeled tiers + a learning-safe gate. Builds on the methodology spike — this is a **stacked PR** (base = `feat/methodology-platform-spike`, which is PR #42 and not yet merged).

## Design (after four evaluation rounds + a Codex adversarial pass on the spike)

- **Deterministic linter (PROVEN tier):** literal rules — em-dash, hashtags, banned words — regex detect + mechanical repair. Each pattern provably runs; scales to thousands; ~free. This is the part we can actually *verify*.
- **Semantic editor (JUDGED tier):** ONE grounded AI pass (find+fix fused) for stylistic tells (negative-parallelism, salesy, generic-AI), grounded in a few-shot tell library **and the methodology's own `voice.antiPatterns`**. Minimal-edit by default (edit only offending sentences); whole-draft escalation available.
- **`cleanPost` loop:** lint → editor → re-lint → gate → `CleanReport`, which separates `mechanicalFixes` (proven) from `aiEdits` (judged) so the ghostwriter knows what to trust vs. confirm.
- **Protected-content invariant:** an AI edit that would drop a client's signature phrase / credential *that was present in the draft* is rejected — the protected-voice guarantee holds **through** repair, by substring check, not trust.
- **Flag-and-surface gate:** unfixable → flagged for the ghostwriter, never silently mangled.
- **Offline eval set** is the semantic quality bar (replaces the per-post "coverage ledger" we cut as theater).

## Deliberately cut (judged over-engineering during design)

Compile-time rule classification, batched semantic sweeps, the coverage ledger. **Deferred (hooks left in):** learning new tells from edits (tells live in the methodology Body, so the convergence loop can propose them later), auto whole-draft escalation, a coherence-check pass.

## Verification

- typecheck clean · **61 tests** · `npm run build` passes.
- **Live editor eval (real model via OpenRouter, 13 labeled fixtures):** `recall=1.00  over-edit=0.00  protected-preservation=1.00` → EVAL PASS.
- **Honest caveat:** 13 fixtures is a *floor*, not proof of field quality, and recall is a proxy (planted-phrase-gone). The linter tier is *proven*; the editor tier is *measured + judged*, with the ghostwriter's review as the real backstop. The eval grows as real labeled posts accumulate.

## How the design got here

Two Codex adversarial findings on the spike were fixed first (shared-methodology pollution → approval-gated + identity-checked proposals; fail-open AI judge → fail-closed). The replacer's own design survived four self-critical rounds: the key correction was *not* trying to regex the hard constructional tells (brittle) — only literal sets are deterministic; everything semantic is one grounded, measured editor pass.
