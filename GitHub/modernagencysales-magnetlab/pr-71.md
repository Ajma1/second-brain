## Summary
- Content queue edits were lost when pressing Cmd+Enter because the debounced save (500ms) was canceled by auto-advancing to the next post
- Now tracks pending content in a ref and flushes it immediately on Cmd+Enter (included in the same API call) and before post navigation (j/k/arrow keys, sidebar click)
