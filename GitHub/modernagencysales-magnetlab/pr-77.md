# fix: prevent cascading re-renders in CopilotNavigatorProvider (MOD-604)

PR #77 in modernagencysales/magnetlab — closed — by cyrusagent[bot] — [https://github.com/modernagencysales/magnetlab/pull/77](https://github.com/modernagencysales/magnetlab/pull/77)

## Summary

- **Memoize `CopilotNavigatorProvider` context value** with `useMemo` — the provider was creating a new value object on every render, causing all 12 dashboard consumers to re-render on any extraneous parent re-render, compounding into a cascading update storm
- **Fix stale `entityTitle` in `useCopilotPageContext`** — `entityTitle` was excluded from the effect dep array (via `eslint-disable`), leaving `pageContext.entityTitle` permanently stale after concept selection in WizardContainer
- **Adds 2 regression tests** for both behaviors

Fixes React error #185 (Maximum update depth exceeded) reported at `/create`.

Closes MOD-604
