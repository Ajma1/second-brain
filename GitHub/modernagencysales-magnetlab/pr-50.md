# feat: Teams V3 — separate access/identity, agency linking, template rerank

PR #50 in modernagencysales/magnetlab — closed — by kimprobably — [https://github.com/modernagencysales/magnetlab/pull/50](https://github.com/modernagencysales/magnetlab/pull/50)

## Summary

- **Separates team access control from content identity** — new `team_members` table (who can work) vs `team_profiles` (who content is published as). Profiles are personas, not access grants.
- **Agency-to-client team linking** — `team_links` table lets an agency team (e.g., MAS) get automatic access to client teams. All agency members see client teams instantly. Adding/removing agency staff propagates automatically.
- **Fixes all copilot team scoping** — every copilot action now uses DataScope-aware repos instead of raw `.eq('user_id')` queries. The broken `team_members.team_id` query (which never worked) is replaced with `getDataScope()`.
- **Fixes MCP team_id pass-through** — all 37 MCP tools now send `team_id` as a query parameter instead of silently discarding it.
- **Template matching rewrite** — shortlist 10 candidates via pgvector, rerank by semantic similarity (0.4) + engagement performance (0.35) + per-profile freshness (0.25), pass top 3 as soft guidance menu. No more "adhere strictly to template" mode.
- **Post writer consolidation** — single `writePost()` entry point. `writePostFreeform()` and `writePostWithTemplate()` deleted.
- **Autopilot team generation** — generates posts for all team profiles with shared idea pool, per-voice writing, and per-profile template freshness.
- **Flexible billing** — `billing_team_id` on teams allows agency to pay for client resources or vice versa.
- **V1 legacy deleted** — `team-membership.ts`, `team.service.ts`, `/api/team/` routes all removed. No compatibility layers.
