# fix(funnel/custom-domain): auto-attach hostname on Vercel to stop DEPLOYMENT_NOT_FOUND

PR #1244 in modernagencysales/mas-platform — closed — by Ajma1 — [https://github.com/modernagencysales/mas-platform/pull/1244](https://github.com/modernagencysales/mas-platform/pull/1244)

## Summary

Funnel-page custom domains (`funnel_pages.custom_domain`) returned `DEPLOYMENT_NOT_FOUND` from Vercel because `setCustomDomain()` only wrote the DB column — the "then add it in Vercel settings" instruction in the JSON response was never surfaced in the UI. Surfaced today by `mediaready.establishcred.com` (client: Sim / EstablishedCred).

DNS resolved correctly (`CNAME → cname.vercel-dns.com`) but Vercel had no project claiming the hostname, so its edge served `X-Vercel-Error: DEPLOYMENT_NOT_FOUND`.

- `setCustomDomain()` now mirrors `setTeamDomain()`: call Vercel `addDomain()` **before** the DB write, persist `vercel_status` + verification records, and roll back the Vercel attach if the DB write fails.
- `removeCustomDomain()` calls Vercel `removeDomain()` before nulling the DB.
- New `POST /api/settings/custom-domain/verify` calls `checkDomain()` so the wizard can re-poll Vercel after DNS propagates.
- PublishControls shows a `pending | verified | error` badge and a **Re-verify** button. The "go add it manually in Vercel" instruction is removed from the UI/note path.
- One-shot backfill script attaches existing `funnel_pages.custom_domain` rows on Vercel; treats `domain_already_in_use` from the same project as success.
- Migration adds `vercel_status text`, `vercel_verification jsonb`, `vercel_last_checked_at timestamptz` to `funnel_pages` (idempotent).
- Tests: 8 service-level + 8 route-level (including the regression guard: `setCustomDomain` MUST call Vercel before the DB write).

## Hot-fix for Sim (separate, manual)

After merge, register `mediaready.establishcred.com` on the apps/app Vercel project (dashboard or `vercel domains add`). Once registered, Vercel auto-issues SSL and the existing CNAME starts resolving immediately. Backfill script will pick up any other rows in the same state.
