# [codex] Add MAS lead magnet Blueprint bridge

PR #1245 in modernagencysales/mas-platform — closed — by kimprobably — [https://github.com/modernagencysales/mas-platform/pull/1245](https://github.com/modernagencysales/mas-platform/pull/1245)

## Summary

Adds a MAS-owned bridge thank-you page for non-Blueprint lead magnet opt-ins. The page delivers the requested resource from URL parameters, pitches the free Blueprint as the next opt-in, submits to the existing Blueprint intake webhook, and hands successful submissions to the existing iClosed booking experience.

## What Changed

- Added `/blueprint/lead-magnet-thank-you` with `lm`, `resource`, optional prefill, and UTM parsing.
- Added a route-local step-through Blueprint intake form and client API wrapper for `/api/webhooks/blueprint-form`.
- Preserved attribution via `source_url`, `lead_magnet_source`, and supported UTM params.
- Hardened public iClosed helper behavior for JSON-stringified emails and malformed phone numbers.
- Added focused tests for bridge parsing, UI/submission behavior, and iClosed normalization.

## Review Notes

- Security review found no blocking issues in the new route: resource URLs are restricted to `http`/`https`, rendered as external links with `noreferrer`, and user-provided copy is rendered through React escaping.
- No new public API endpoint was added; the page uses the existing same-origin Blueprint webhook.
- The existing `blueprint-form` webhook is unsigned by design and tenant-pinned by existing resolver behavior.
