# fix(copilot): generate_lead_magnet_posts honours team scope

PR #1247 in modernagencysales/mas-platform — closed — by Ajma1 — [https://github.com/modernagencysales/mas-platform/pull/1247](https://github.com/modernagencysales/mas-platform/pull/1247)

## Summary
- `generate_lead_magnet_posts` failed with `Lead magnet not found: <id>` for team-shared magnets (reported by saket's workspace, magnet `1381093d-dd1c-4b8a-b495-8604ae09969e`).
- Root cause: handler stripped `ctx.scope` → `ctx.scope.userId`; `generatePosts()` then filtered `lead_magnets` by `user_id` only, so any magnet whose owner ≠ caller (team-shared, created by another member, impersonation, V4.2 backfill-rewritten) returned 404.
- Fix: plumb full `DataScope` into `generatePosts`. Lookup now mirrors `findLeadMagnets` in `lead-magnets.repo.ts` — personal scope filters by `user_id`, team scope uses `team_id.eq.<teamId>,user_id.eq.<userId>` so callers see team-shared + their own personal magnets. Brand-kit / post-writer downstream still keyed by caller's `user_id` (widening those is a separate follow-up).
