# fix(csp): unblock iclosed + calendly booking widgets

PR #1224 in modernagencysales/mas-platform — closed — by kimprobably — [https://github.com/modernagencysales/mas-platform/pull/1224](https://github.com/modernagencysales/mas-platform/pull/1224)

## Summary

\"Book Your Call\" widget on funnel thankyou pages rendered the heading but the iframe never appeared. Cause: CSP \`script-src\` allowed Stripe / PostHog / Vercel only — the browser silently blocked \`https://app.iclosed.io/assets/widget.js\`. \`frame-src\` already allowed the iframe itself, which masked the cause.

## Reproduction

\`\`\`
curl -sLI https://app.maestrogtm.com/p/tim-keen/99-gtm-tips/thankyou \\
  | grep -i content-security
# script-src 'self' 'unsafe-inline' 'unsafe-eval' https://js.stripe.com ...
# (no app.iclosed.io)
\`\`\`

Verified the widget script is otherwise healthy (HTTP 200, 3220B, valid JS). The script reads \`document.currentScript\`, scans \`.iclosed-widget\` divs, and injects an iframe — it just never executes when CSP blocks it.

## Changes

Added to CSP:
- \`script-src\`: \`app.iclosed.io\`, \`assets.calendly.com\`, \`cdn.jsdelivr.net\` (iclosed's widget.js dynamically imports React from jsdelivr for its CTA widget)
- \`style-src\`: \`app.iclosed.io\`, \`assets.calendly.com\` (widget.js fetches its own \`/widget.css\`)
- \`connect-src\`: \`app.iclosed.io\`, \`assets.calendly.com\`, \`calendly.com\`
- \`frame-src\`: \`calendly.com\` (was missing — only \`cal.com\` and \`app.iclosed.io\` were present)
