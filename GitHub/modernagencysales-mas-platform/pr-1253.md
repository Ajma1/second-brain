## Summary
- **Hotfix** — Blueprint form at modernagencysales.com returning 500 "Failed to create pipeline record", blocking all new leads
- Replaces the global unique index `reply_pipeline_linkedin_url_unique` with a per-tenant unique index — each tenant can now have its own pipeline record for the same LinkedIn URL
- Adds a global fallback in the 23505 recovery path so any constraint violation returns a duplicate response instead of 500

## Root cause
Global unique index on `reply_pipeline.linkedin_url` blocks one row per URL across ALL tenants. The dedup check filters by `tenant_id`, so cross-tenant duplicates are invisible → insert fails → 23505 recovery has the same blind spot → 500.
